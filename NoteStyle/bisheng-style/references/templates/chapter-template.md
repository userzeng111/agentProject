# 章节模板

> 笔生创作系统 · 执行层核心模板

## 章节定位

| 字段 | 内容 |
|------|------|
| 卷/章编号 | 第[X]卷 第[X]章 |
| 在节奏曲线中的位置 | [开篇/发展/高潮/收束/过渡] |
| 本章核心目标 | [用一句话说明本章要完成什么] |
| 承接上章 | [从哪个状态开始] |
| 连接下章 | [下章的入口状态] |

## 风格参数卡

从语言DNA中加载当前场景类型的参数：

| 参数 | 目标值 |
|------|--------|
| 本章主要场景类型 | [对话/独处/冲突/日常/高潮] |
| 目标句长 | [X]字 |
| 对话占比 | [X]% |
| 口语化程度 | [1-5级] |
| 幽默密度 | [X]处/千字 |
| 环境描写 | [仅在女性出场或情感转折点] |
| 旁白限制 | [最多补刀1-2句] |
| 本章使用的叙事DNA | [DNA-1, DNA-3, ...] |
| 本章情感基调 | [搞笑为主/甜蜜为主/温馨为主/虐心为主] |

## 四段式结构

### 第一段：钩子（占20%篇幅）
- **开场方式**：[用一个引人好奇的场景/对话/内心独白开头]
- **建立预期**：[让读者知道本章要讲什么]
- **字数参考**：[X]字

### 第二段：展开（占30%篇幅）
- **核心冲突/事件**：[本章的主要事件]
- **推进方式**：[对话为主/事件为主/心理为主]
- **人物互动**：[哪些角色有对手戏]
- **字数参考**：[X]字

### 第三段：情感落脚（占30%篇幅）
- **情感类型**：[甜蜜/搞笑/温馨/虐心]
- **表达方式**：[小动作+小对话 / 克制留白 / 反差爆发]
- **核心场景**：[最能打动读者的一个画面]
- **字数参考**：[X]字

### 第四段：章末钩子（占20%篇幅）
- **钩子类型**：[悬念/反转/预告/情感/冲突]
- **具体设计**：[最后1-2段如何制造期待感]
- **字数参考**：[X]字

## 创作自检清单（9项）

每章完成后逐项检查：

- [ ] **1. 语言DNA吻合**：句长、口语化、口癖使用是否符合风格参数卡
- [ ] **2. 叙事DNA应用**：本章计划使用的叙事DNA是否都体现了
- [ ] **3. 人物行为一致**：角色的言行是否符合其人物设定卡和矛盾矩阵
- [ ] **4. 对话个性化**：遮住名字能分辨谁在说话
- [ ] **5. 情节推进效率**：本章至少推进了一个信息点或情感点
- [ ] **6. 情感真实度**：不是空泛抒情，是通过具体细节传递情绪
- [ ] **7. 节奏感**：快慢交替得当，没有连续长段落或纯对话堆砌
- [ ] **8. 章末钩子**：有明确的钩子制造阅读动力
- [ ] **9. 前后连贯**：与上章衔接自然，时间线/空间/角色状态无矛盾

---

## 失真审校（7项）

创作完成后，从"是否偏离风格"的角度额外检查：

- [ ] **1. 表层模仿**：是否只学到了嘴贫和装逼，缺少深层质感
- [ ] **2. 情感表达**：是否缺失参考样本那种情感拉扯
- [ ] **3. 生活锚点**：是否缺少日常生活的烟火气
- [ ] **4. 女角色**：是否把女性角色工具化、缺少独立人格
- [ ] **5. 事业线**：是否变成枯燥的说明书
- [ ] **6. 爽点重复**：是否连续多章用同一种爽点
- [ ] **7. 原书映射**：是否直接复制了参考书的桥段
