# 写作DNA提炼方法论

> 从原始文本到可运行的写作规则，笔生的核心方法论

## 一、写作模式三重验证

一个写作特征要被确认为「核心写作DNA」而非「偶尔为之」，必须通过三重验证。

### 验证1：跨章节复现

同一个写作模式在全书中不同章节、不同场景反复出现（>=5次）。

示例：
- 「高对白快推进」出现在宿舍日常、酒桌社交、恋爱对话、师生交流——跨4类场景复现 → 通过
- 「某章出现一次的倒叙手法」——仅出现1次 → 不通过

### 验证2：生成力

掌握这个模式后，能指导新故事的创作，且生成的文本能被辨认出属于同一风格体系。

示例：
- 规则「环境描写只在女性角色出场和情感转折点出现，其余场景不写」→ 可以在新故事中复现 → 通过
- 规则「第7章用了一个特殊的双线交叉叙事」→ 太具体，不可复现 → 不通过

### 验证3：排他性

不是所有同类作者都这样写，这个模式体现了目标作者的独特性。

示例：
- 「70%日常+30%主线，日常中暗埋主线线索」→ 同类作品中不常见的配比 → 通过
- 「用对话推进情节」→ 网文普遍做法 → 排他性不足，降级为辅助技巧

### 降级规则

| 验证结果 | 处理 |
|---------|------|
| 三重全通过 | 核心写作DNA，优先级最高 |
| 跨章节+生成力通过 | 辅助写作技巧，可用但非标志性 |
| 仅跨章节通过 | 参考素材，不作为风格约束 |
| 跨章节未通过 | 丢弃 |

## 二、写作DNA十维度模型

```
写作DNA = 叙事DNA + 语言DNA + 人物DNA + 情节DNA + 情感DNA
         + 信息编码 + 对话声学 + 动作编码 + 修辞签名 + 母题变奏
```

> 前五层是宏观结构（回答"作者做了什么"），后五层是微观技法（回答"作者怎么做到的"）。
> 95%以上的文风还原度需要十层全部覆盖。

### 2.1 叙事DNA（宏观）

提炼维度：

| 维度 | 提炼重点 | 量化方法 |
|------|---------|---------|
| 视角模式 | 叙事紧贴谁？切换频率？ | 统计视角切换次数/总段落数 |
| 叙事节奏 | 快慢交替的规律 | 段落长度方差、动作密度 |
| 信息控制 | 信息差如何利用？伏笔回收方式 | 标注信息揭露节点 |
| 旁白风格 | 旁白的长度、口吻、功能 | 统计旁白句数/总句数 |
| 内心独白 | 独白嵌入方式、与叙事的切换 | 统计独白密度 |
| 叙事距离 | 远景→中景→近景→内心的切换模式 | 标注每段叙事距离等级 |

### 2.2 语言DNA（宏观+微观）

#### 句式指纹（基于30+段落样本统计）

| 维度 | 测量方式 | 目标用途 |
|------|---------|---------|
| 平均句长 | 字数/句数 | 控制节奏感 |
| 短句占比 | <10字句子/总句数 | 衡量口语化程度 |
| 对话密度 | 对话字数/总字数 | 衡量叙事方式 |
| 描写密度 | 环境描写字数/总字数 | 衡量氛围营造 |
| 心理密度 | 内心独白字数/总字数 | 衡量情感深度 |

#### 风格标签8维量化（1-5分量表）

```
书面 ←→ 口语化        [1---2---3---4---5]
严肃 ←→ 轻松          [1---2---3---4---5]
内敛 ←→ 外放          [1---2---3---4---5]
慢节奏 ←→ 快节奏      [1---2---3---4---5]
含蓄 ←→ 直白          [1---2---3---4---5]
文艺 ←→ 通俗          [1---2---3---4---5]
细腻描写 ←→ 对话驱动  [1---2---3---4---5]
压抑 ←→ 爽感          [1---2---3---4---5]
```

#### 口癖与禁忌词

- 高频词TOP50中过滤通用词，剩余为此作者特有口癖 → 创作时适度使用
- 与同类作品对比，找出此作者几乎不使用的词 → 创作时禁止使用

#### 场景类型差异化参数

同一作者在不同场景中的语言参数不同：

| 场景类型 | 对话占比 | 句长 | 口语化 | 幽默密度 |
|---------|---------|------|--------|---------|
| 对话/社交 | >60% | 短 | 极高 | 高 |
| 独处/思考 | <30% | 长 | 低 | 低 |
| 冲突/对峙 | 中 | 极短 | 高 | 中 |
| 日常/闲笔 | 中 | 中 | 中 | 中 |
| 情感/高潮 | 中 | 长短交替 | 中 | 低 |

#### 句式节奏指纹（微观）

提炼原作的"呼吸节奏"——长短句交替的具体模式：

| 节奏阶段 | 句式特征 | 功能 |
|---------|---------|------|
| 铺陈段 | 长句（30-60字），一个完整画面 | 缓慢吸入 |
| 对话段 | 短句（5-15字），2-3轮排比 | 快速推进 |
| 爆发点 | 单字/拟声词/极短动作 | 冲击 |
| 回落段 | 哲理句/旁白/感慨（10-20字） | 呼出 |

### 2.3 人物DNA（宏观+微观）

#### 人物原型提炼

每个人物原型包含：

| 字段 | 说明 |
|------|------|
| 核心特征 | 用3个关键词概括此类型角色 |
| 出场方式 | 首次出场如何建立印象 |
| 对话风格 | 标志性语言习惯（口癖、句式、语气） |
| 行为模式 | 典型场景下的标准反应 |
| 情感表达 | 喜欢/不满/脆弱/愤怒各怎么表现 |
| 矛盾矩阵 | 基准特质 vs 触发特质（什么条件下展现反差面） |
| 动作指纹 | 此角色特有的物理动作模式（力度、方向、频率） |
| 语言指纹 | 此角色的语法偏好（结巴、倒装、省略、口癖位置） |

#### 主角塑造方法论

- **"不做什么"塑造法**：主角的辨识度来自他"不做什么"（不慌张、不解释、不炫耀）
- **克制力展示**：每一个社交场景中展现"精准控制力"
- **反差利用**：成年人的认知+青春的场景=独特的"社会人感"

#### 配角塑造方法论

- **一句话定人**：首次出场用一句包含性格特征的对话"盖章"
- **功能化设计**：每个配角服务明确的叙事功能（衬托主角/推动情节/制造冲突）
- **标签强化**：后续出场只需要强化标签，不需要发展弧光

### 2.4 情节DNA（宏观）

| 维度 | 提炼重点 |
|------|---------|
| 单章结构 | 典型的章节内部结构模式（如四段式） |
| 章末钩子 | 哪些类型的钩子？分布频率？ |
| 大节奏节点 | 每多少章推进一次主线？ |
| 多线交织 | 几条主线？如何交替？交汇频率？ |
| 伏笔管理 | 伏笔密度？回收周期？ |
| 日常与主线比例 | 典型的日常/主线配比 |

### 2.5 情感DNA（宏观+微观）

#### 情感四层体系

| 层次 | 定义 | 标志 | 典型占比 |
|------|------|------|---------|
| 甜蜜层 | 角色间的亲密信号 | 肢体接触、甜蜜对话、默契 | 25% |
| 搞笑层 | 打破紧张的幽默 | 吐槽、意外反应、反差萌 | 15% |
| 温馨层 | 安全感和归属感 | 日常细节、无压力陪伴 | 35% |
| 虐心层 | 情感痛苦和不确定 | 误解、错过、隐忍、牺牲 | 25% |

#### 情感曲线模式

逐段标注情感基调值（1-10），连线形成曲线。提炼出：
- 标准章节的情感曲线模板
- 情感转折点的触发条件
- 虐心场景的铺垫→爆发→消解周期

#### 情感留白手法

- 角色想表达但没表达的比例（目标>30%）
- 不写悲伤写沉默，不写痛苦写日常中的缺失
- 用动作和短对话传递情绪，禁止超过3句的纯抒情

#### 情感物理化（微观）【关键新维度】

把情感翻译成身体语言。提炼原作中每个情感的"身体出口"：

| 情感 | 物理化方式 | 原作示例 |
|------|----------|---------|
| 心疼 | 胸口的紧缩/抽搐感 | "心里那块柔软的地方一抽一抽的" |
| 惊慌 | 手的失控 | 打翻饭碗 |
| 愤怒 | 面部充血+原始冲动 | 咬/砸/拍 |
| 暗恋 | 远距离注视 | 食堂角落的偷看 |
| 委屈 | "差点"但不完整表达 | "差点哭出声"但没哭 |
| 爱意 | 替对方做事/照顾 | 擦眼泪、推鱼虾 |
| 示弱 | 最小力度的回避 | 用食指推碗而非双手推开 |

**核心原则**：永远不要写"他感到X"——而是找到X的物理表现，让读者自己"感受"。

### 2.6 信息编码密度（微观）【新增核心维度】

**定义**：单句/单段文字中同时承载的叙事信息层数。高水准小说一句话往往同时完成"叙事推进+人物刻画+情感暗示+氛围营造+伏笔埋设"五重任务。

**提炼方法**：

选取10个代表性句子，逐句拆解信息层：

| 句子 | 第1层·叙事 | 第2层·人物 | 第3层·情感 | 第4层·氛围 | 第5层·伏笔 |
|------|----------|----------|----------|----------|----------|
| （填入） | ... | ... | ... | ... | ... |

**创作公式**：

```
高密度信息句 = [环境/氛围锚点] + [人物对物/人的物理反应] + [用"物"替代心理描写] + [一个精准修饰词调节节奏]
```

**自检标准**：创作时每3句话中至少1句承载>=3层信息。如果一句话只推进了一层信息，删除或合并。

### 2.7 对话声学（微观）【新增核心维度】

**定义**：角色对话的表层意义与潜台词之间的落差系统。

**提炼方法**：

选取15段关键对话，标注每段的"表层意思"和"潜台词"：

| 对话原句 | 表层意思 | 潜台词（真实意图） | 信息差类型 |
|---------|---------|-----------------|----------|
| （填入） | ... | ... | ... |

**信息差类型分类**：
- **反向表达**：想靠近时故意拉远（请客→不是施舍而是保护自尊）
- **惩罚性冷漠**：想挽留时故意推走（OK，那就这样吧）
- **沉默即回应**：不回应本身就是回应（沈幼楚的沉默=同意+害羞）
- **命令式温柔**：关心用命令语气表达（"你帮我带这个"=亲密占有）

**角色语言指纹提炼**：

| 角色 | 结巴/犹豫标记 | 口癖 | 语法特征 | 潜台词模式 |
|------|-------------|------|---------|----------|
| （填入） | ... | ... | ... | ... |

### 2.8 动作信息编码（微观）【新增核心维度】

**定义**：物理动作的方向+力度+结果 = 人物性格和关系的物理映射。

**提炼方法**：

标注原作中所有关键身体动作，拆解编码：

| 动作 | 执行者 | 力度 | 方向 | 物理结果 | 编码信息 |
|------|-------|------|------|---------|---------|
| 弹名片 | 陈汉升 | 轻 | 向外/向下 | 被车轮碾压 | 从容的不屑 |
| 推鱼虾 | 沈幼楚 | 极轻 | 向外 | 碗移了几厘米 | 不知所措的回避 |
| 掏钱包 | 沈幼楚 | 仔细 | 向外 | 硬币排成一列 | 沉默的尊严 |

**创作公式**：

```
动作编码 = [特定身体部位] + [精确的力度词] + [可见的物理结果] + [隐含的心理暗码]

不同角色的动作对比：
- 自卑者：动作小、收缩性、回避接触
- 自信者：动作大、外放性、主动制造接触
- 压抑者：动作犹豫、半途而止
- 关怀者：动作轻柔、替代对方完成某事
```

### 2.10 母题变奏（微观）【新增核心维度】

**定义**：核心物品/动作/对话在全书中反复出现，每次出现时意义螺旋升级。

**提炼方法**：

识别全书中反复出现的物品、动作或对话（>=3次），追踪其意义演变：

| 母题 | 第1次出现·基础意义 | 第2次出现·意义升级 | 第3次出现·意义升华 |
|------|-----------------|-----------------|-----------------|
| （物品名） | ... | ... | ... |

**创作公式**：

```
母题变奏三步法：
1. 建立基础意义（A = X）——首次出现时赋予简单含义
2. 加入新语境，旧意义被挑战（A = X + Y）——第二次出现时改变语境
3. 完全反转或升华原始意义（A ≠ X, A = Z）——第三次出现时意义质变
```

除核心母题外，追踪原作中"看似不重要但后续变得重要"的小物件/小动作：

| 种子 | 首次出现（章节） | 发芽（章节） | 开花/枯萎 |
|------|---------------|------------|----------|
| （小物件/动作） | 看似随意的细节 | 再次出现，开始有意味 | 意义质变或沉默 |

## 三、矛盾处理原则

### 矛盾是创作资源，不是需要修复的Bug

#### 言行矛盾 → 角色深度

角色嘴上说的（社会面具）vs 实际做的（真实自我），两者之间的差距就是"角色深度"。
- 规则：不在文本中明确指出言行不一，让读者自己发现

#### 前后矛盾 → 角色弧光

标记"基准特质"（90%时间展现）vs"触发特质"（特定情境下展现），两者统一于核心需求。
- 规则：关键转折点必须是矛盾面的切换时刻

#### 关系矛盾 → 情感张力

任何一对关系都存在至少一个"核心矛盾"，不需要解决，只需要"被看见"。
- 规则：最高级的关系矛盾是双方都觉得自己是对的

#### 叙事矛盾 → 阅读快感

角色内心独白说A，行为暗示B，其他角色观察认为C，读者综合得出D——四个版本都是"真相"的一部分。

## 四、信息不足处理

| 情况 | 处理方式 |
|------|---------|
| 某维度样本信息很少 | 在Skill中标注「信息不足，此维度为推测」 |
| 风格前后有变化 | 记录演化轨迹，标注「早期」「近期」，以近期为主 |
| 特征相互矛盾且无法判断 | 并列呈现，让用户自行判断 |
| 作者刻意避免某方面 | 尊重边界，注明「此作者对此话题保持沉默」 |

## 五、质量自检清单（十维度版）

生成风格Skill后，用以下标准自检：

### 宏观五维度

#### 叙事DNA（2.1）
- [ ] 3-7条核心规则，每条>=3个场景证据？
- [ ] 每条都有明确的应用场景和失效条件？
- [ ] 规则之间有张力但不矛盾？
- [ ] 叙事距离控制模式已提炼（远景→近景→内心切换规律）？

#### 语言DNA（2.2）
- [ ] 句式指纹全部量化（平均句长、短句占比、对话密度、描写密度、心理密度）？
- [ ] 8维风格标签已填写（书面-口语、严肃-轻松等）？
- [ ] 口癖和禁忌词有黑白名单（TOP50去通用词后）？
- [ ] 场景类型差异化参数卡已完成（对话/独处/冲突/日常/情感各场景的参数）？
- [ ] 句式节奏指纹已提取（铺陈段/对话段/爆发点/回落段的特征）？

## 六、蒸馏操作流程

### Step 1：样本抽样
- 从原文中均匀抽取30+个代表性段落
- 覆盖：开场、日常、冲突、恋爱、离别、搞笑、亲情、事业推进
- 每段50-200字

### Step 2：逐维度提取（十维度并行）

**宏观五维度**：
- 叙事Agent → 叙事DNA（含叙事距离控制模式）
- 语言Agent → 语言DNA（含句式节奏指纹+场景差异化参数）
- 人物Agent → 人物DNA（含动作指纹+语言指纹+矛盾矩阵）
- 情节Agent → 情节DNA
- 情感Agent → 情感DNA（含情感物理化对应表+留白手法）

**微观五维度**：
- 信息编码Agent → 信息编码密度（10句逐句5层拆解）
- 对话Agent → 对话声学（15段潜台词标注+角色语言指纹）
- 动作Agent → 动作信息编码（关键动作拆解+角色对比模式）
- 修辞Agent → 修辞签名（比喻来源域+通感模式+反讽分类）
- 母题Agent → 母题变奏（>=3个母题的意义演变追踪）

- 世界观Agent → 时代标志物/设定体系

### Step 3：三重验证筛选
- 从Step 2的候选中列出15-30个论点
- 逐个进行三重验证
- 按排他性强度排序，取top 3-7个为每个维度的核心DNA

### Step 4：量化补充
- 对语言DNA进行8维量表量化
- 对情感DNA进行四层比例统计
- 对场景类型参数进行分场景统计

### Step 5：矛盾记录
- 记录所有发现的矛盾
- 分类为创作资源型（利用）vs 创作失误型（消除）
- 为角色建立矛盾矩阵

### Step 6：质量自检
- 按第五节清单逐项检查
- 不通过项进行补充分析或标注诚实边界
