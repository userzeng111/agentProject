# 人物特化规则 — 唐家三少风格实例

## 人物出场模式："外貌速写+身份标签"

每个新人物出场，固定模式：
1. 年龄→身材→面容→穿着→身份标签
2. 紧接着给出等级/职业/能力标签

**正向示例**：
```
此人看上去二十多岁的样子，剑眉星目，相貌甚是俊朗。一身白色劲装，背后是黑色披风，
胸前正中心的位置，有一个拳头大小的魂字。左胸上，有一枚雕刻着长剑的徽章，
徽章上一共是三柄长剑交错。
```

**反向示例**（柳岸花又明式，禁用）：
```
他叼着烟站在走廊里，浑身上下散发着一种"别惹我"的气息。
```

---

## 主角塑造："旁白盖章+分析型独白"

唐三的人物深度来自：
1. 叙述者直接评价（"唐三是一个心志坚定的人"）
2. 逻辑分析型内心独白
3. 修炼/战斗中的行为展现

**禁用**：
- "言行矛盾"塑造法（唐三的言行高度一致）
- 痞气包裹深情
- 逆向表达（唐三想的就说他想的）

---

## 配角处理：高度功能化

配角出场即定型，不进行弧线变化。配角功能分类：

| 配角类型 | 功能 | 示例 |
|---------|------|------|
| 导师型 | 提供设定解说和修炼指导 | 大师（玉小刚） |
| 战友型 | 战斗配合+简短情感互动 | 史莱克七怪 |
| 对手型 | 展示实力差距/提供挑战 | 各学院对手 |
| 路人型 | 提供信息或衬托主角 | 老杰克、素云涛 |

**对话辨识度**：角色语言差异不大，主要靠说话内容和身份标签区分。不需要"遮住名字能分辨谁在说话"的强辨识度要求。

---

## 女性角色描写

描写顺序固定：身高→身材→面容→发色→穿着。形容词偏向"精致""美丽""绝色"等直接评价。

**禁用**：
- 极文学描写（白月光型/宝藏型三步法不适用）
- 通感收束（唐家三少不使用高级修辞描写女性）
- 物件中转式情感表达
