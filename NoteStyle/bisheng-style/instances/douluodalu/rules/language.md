# 语言特化规则 — 唐家三少风格实例

## 叙述语言："浅文学体"

介于文学体与口语体之间。不是纯口语，但也不追求深度文学性。

**核心特征**：
1. **四字成语高频**：精神矍铄、面不红气不喘、怡然自得、剑眉星目、纹丝不动
2. **"XX的XX"句式**："冷淡的道""苦涩的自言自语的道""静静的看着""冷冷的瞥了他一眼"
3. **明喻模板**："如同……一般""宛如……一般""像是……似的"——固定化修辞
4. **术语密集**：玄天功、紫极魔瞳、蓝银草、魂环、魂技、武魂融合技、海神三叉戟
5. **中短句为主**（15-25字），叙述标签（"XX道"）使用频率极高

---

## 主角内心独白：分析型而非情绪型

唐三的内心独白是逻辑推理和分析，不是情感宣泄。即使在激动时，独白也是"分析局势→制定策略→自我激励"。

**模板**：
```
[观察现象] → [分析原因] → [推导结论] → [制定策略]
例："玄天功第一重的瓶颈却像是坚不可摧的壁垒，唐三的修炼不可谓不刻苦，他的天份也足够，可就是无法突破而进入第二重。"
```

**禁用**：
- 粗口/俚语包裹深情（唐家三少不使用痞气层）
- 文艺腔感慨（"时光如水""岁月如歌"）
- 口语化独白（"妈的""操"）

---

## 自造词/术语系统

每个故事必须创造大量术语，构成"术语美学"：

| 术语类型 | 说明 | 示例 |
|---------|------|------|
| 功法术语 | 修炼方法的专有名称 | 玄天功、紫极魔瞳、玄玉手、鬼影迷踪 |
| 力量体系术语 | 等级/分类的专有名称 | 武魂、魂环、魂技、魂力、封号斗罗 |
| 物品术语 | 重要道具的专有名称 | 蓝银草、佛怒唐莲、海神三叉戟 |
| 战斗术语 | 技能/招式的专有名称 | 武魂融合技、领域技能、无敌金身 |

**使用规则**：
- 术语首次出现必须附带解释（通过叙述者或对话）
- 术语重复使用形成读者记忆
- 术语体系有明确等级递进

## 幽默配方

唐家三少的幽默极少，整体基调是正经严肃。偶尔的幽默来自：
1. **反差幽默**：小舞的活泼行为与唐三的冷静分析形成反差
2. **配角插科打诨**：马红俊、奥斯卡等配角的简短搞笑台词
3. **不自知的夸张**：某些设定的过度认真化带来的效果
