# 编码规则 — 唐家三少风格实例

## 信息编码密度标准

低密度铺陈为主。一句话承载1-2层信息是正常的，不需要追求"每3句>=1句承载3层信息"的高密度编码。

**核心原则**：世界观设定通过叙述者旁白和角色对话分多句灌输，不追求单句多义。

**密度规则**：
- 叙述者旁白：1句话1-2层信息，设定可以分多段解释
- 角色对话：设定解说可以连续数页，不需要压缩成高密度金句
- 内心独白：分析型推进，每步推理清晰，不追求一句话包含多层含义
- 环境描写：服务于世界观建立，可以详细铺陈

---

## 动作信息编码

战斗和修炼是唐家三少风格的核心动作段落，需要详细的过程描写。

**战斗/修炼描写密度**：每2-3章安排一次战斗或修炼的详细描写段落。

**动作编码规则**：
1. 战斗过程必须拆解为具体步骤：起手式→魂技释放→对手反应→策略调整→胜负结果
2. 修炼过程必须展示瓶颈、尝试、突破的完整链条
3. 每个动作段落至少包含一个术语使用（魂环名/魂技名/功法名）
4. 叙述者可以在动作段落中插入力量体系解释

**战斗段落模板**：
```
[对手能力描述] → [主角分析对手弱点] → [主角选择策略] → [招式交锋详细过程] → [胜负结果+叙述者评价]
```

**超长处理优先级**：优先删除重复的心理分析 → 冗余的战斗细节 → 过长的对话

---

## 叙述标签密度

"XX道"类标签每段对话都应使用，不需要省略。

**标签使用规则**：
1. 每段对话必须带有"XX道"标签
2. 允许在标签中嵌入情绪修饰（"冷冷的道""沉声道"）
3. 不追求省略标签来提升流畅度——标签的高频使用是风格特征
4. 对话段落之间不需要动作过渡，直接用标签切换说话人即可

---

## 母题变奏系统

唐家三少风格的母题是力量体系术语，通过反复使用和升级来构建世界观的一致性。

**三大母题体系**：

| 母题类型 | 贯穿方式 | 变奏方法 |
|---------|---------|---------|
| 功法母题（如星陨诀/玄天功） | 主角修炼体系的核心，从第一章贯穿到结局 | 每次突破新等级时，功法展现新效果，旧术语承载新含义 |
| 技能母题（如破晓剑/蓝银草） | 主角的标志性战斗手段，读者通过术语识别角色 | 技能随等级提升解锁新形态，同一术语在不同阶段含义不同 |
| 资源母题（如灵石/魂环） | 力量体系的物质载体，驱动情节获取和分配 | 资源的稀缺性和争夺制造冲突，同一资源在不同情境价值不同 |

**母题使用规则**：
1. 术语首次出现必须附带解释（通过叙述者或对话）
2. 术语重复使用形成读者记忆——同一个术语至少出现3次以上
3. 术语体系有明确等级递进（白魂环<黄魂环<紫魂环<黑魂环<红魂环）
4. 每章至少使用1处已有术语，维持世界观连贯性
5. 新术语的引入节奏：每3-5章引入1-2个新术语，不集中爆发

**母题变奏检验**：
- 把一个术语从文中抽掉，这个场景是否还能成立？如果还能成立，说明术语只是装饰而非骨架
- 同一个术语在故事前期和后期的含义是否发生了质变？如果没有，说明母题没有真正变奏
