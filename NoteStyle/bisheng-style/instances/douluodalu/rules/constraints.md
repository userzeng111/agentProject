# 创作参数约束 — 唐家三少风格实例

## 章节长度 [用户硬性要求，不可更改]

| 指标 | 值 |
|------|-----|
| 目标区间 | 2300-3500字 |
| 黄金区间 | 2600-3200字 |
| 硬下限 | 2300字 |
| 硬上限 | 3500字 |

注：此参数为用户指定硬性要求，不允许修改。原作中期章节（第101-400章）集中在2500-3000字区间，2300-3500的目标区间对应原作叙事节奏最成熟、信息密度最均衡的阶段。每章完成后必须统计字数（带标点，去空白），不在2300-3500区间内则必须修改。

## 对话密度

对话占比约30-40%，主要用于设定解说和信息传递。

## 环境描写频率

每个新场景必须描写环境。已有场景可以简化。

## 设定解说密度

每章至少1处设定解说或力量体系解释。

## 战斗/修炼描写密度

每2-3章安排一次战斗或修炼的详细描写段落。

## 超长处理

优先删除顺序：重复的心理分析 → 冗余的战斗细节 → 过长的对话

## 过短处理

加"设定解说"或"修炼/战斗动作拆解"，不加纯环境描写凑数。

## 信息编码密度

低密度铺陈为主。不需要"每3句>=1句承载3层信息"的规则。一句话承载1-2层信息是正常的，世界观设定通过叙述者旁白和角色对话分多句灌输。

## 叙述标签密度

"XX道"类标签每段对话都应使用，不需要省略。
