# 对话规则 — 柳岸花又明风格实例

## 痞气包裹深情的对话模式

> 原作指纹：陈汉升的对话永远带着一层粗口/俚语/自嘲——他骂骂咧咧地做深情的事。

**核心原则**：主角的对话必须有两层——**表面是粗口/吐槽/自嘲，底层是真实情感**。绝不允许"干净"的深情。

**口吻三要素**（每段关键对话至少包含1个）：
1. **粗口/俚语触发器**：在情感涌上来的瞬间，先用"妈的""操""狗日的"引爆
2. **自我拆穿**：说完真心话后立即自嘲一句，暴露自己的虚伪/算计/不好意思
3. **降维对比**：用前世/成年人的标准嘲笑自己此刻的幼稚反应

**终极比例规则**：
- 粗口:干净深情 = 2:1
- 如果一段深情台词没有粗口/自嘲包裹，必须在前面加一句降温（自嘲、粗口或"说出来矫情"式否定）

**禁用**：
- 纯净的深情台词（"我一直在等你"——必须加痞气包裹）
- 文艺腔感慨（"时光如水""岁月如歌"）
- 客观冷静的情感表达

## 安静型女主口语规则（温以宁型）

> 安静型女主不是说标准普通话。她的口语特征通过"句尾语气词""犹豫标记""说话习惯"来体现性格。

**口语特征三要素**（安静型女主每段对话至少体现1个）：
1. **句尾语气词**：说话习惯性句尾加"的""吧""呢"，不是标准陈述句结尾
   - "我去上课了" → "我去上课了的"
   - "没关系" → "没关系的吧"
2. **犹豫标记**：说话前或说话中有"我……""那个……""嗯……"等犹豫起手式
   - "不用等我" → "我……不用等我的"
   - "谢谢你" → "嗯……谢谢你"
3. **极短句替代**：用"嗯""好""哦"代替完整回答
   - 别人问三句话，她只回一个"嗯"——但这个"嗯"的语气传递的信息比三句话还多

**禁用**：
- 安静型女主说完整标准普通话长句
- 安静型女主的对话和叙述者旁白用同样的句式节奏

## 旁观者群像台词规则

> 原作指纹：几乎每章都有"围观群众"制造喜剧效果，这些旁观者不推进主线，但制造"社会压力的微观缩影"。

**旁观者类型**：

| 类型 | 功能 | 台词特征 |
|------|------|---------|
| 路人围观者 | 对主角行为制造社会压力 | 一句吐槽，不超过15字 |
| 社交圈旁观者 | 对主角的情感状态八卦 | 推理式短句，"有故事吧？" |
| 长辈旁观者 | 用上一代标准评价主角 | 方言短句，"中""咋了" |
| 环境NPC | 用一两句话勾勒时代氛围 | 一问一答，用完即走 |

**台词规则**：
1. 旁观者台词不超过3句，用完即走
2. 旁观者的评价必须带"误解"——他们看到的和真相不同（喜剧来源）
3. 主角对旁观者的反应是"不当回事"或"顺着演下去"，不是尴尬
4. 禁忌：旁观者不能变成说教工具（不能通过旁观者讲道理）

## 主角逆向表达规则

> 原作指纹：陈汉升的真实意图永远藏在他话语的"反面"——他说不在乎的时候最在乎，说"算了"的时候最不想算。

**逆向表达三模式**：

| 模式 | 表现方式 | 示例 |
|------|---------|------|
| 否定式肯定 | 用"不"来表达"是" | "我才没有在想她"（其实一直在想） |
| 贬低式重视 | 用贬低来掩饰在意 | "就她那样"（说完眼睛还在看） |
| 逃避式回应 | 用转移话题来回避真实感受 | 问"你是不是喜欢她？"→ 答"走，吃饭去" |

**使用规则**：
1. 逆向表达只出现在对话和外在行为中，内心独白是真诚的（读者通过独白知道真相）
2. 逆向表达的"拆穿"必须由旁观者或对方角色完成，不能由叙述者直接说明
3. 每次逆向表达后必须有对应的"暴露时刻"——某个细节出卖了真实情感（看了一眼、停顿了一秒、手里的烟灭了没发现）
4. 禁止过度使用——如果主角每句话都是逆向表达，读者会失去信任感

**角色语言指纹规则**（每人至少1个口癖）：
- 主角：粗口+自嘲口吻（"妈的""操""来都来了"）
- 话痨配角：夸张口头禅（"卧槽""嗷""嘿嘿"）
- 老一辈：方言短句（"中""咋了""老实说"）
- 女主A（萧容鱼型）：直接/犀利（"切""呵""没意思"）
- 女主B（沈幼楚型）：极简/犹豫（"嗯""...好"）
