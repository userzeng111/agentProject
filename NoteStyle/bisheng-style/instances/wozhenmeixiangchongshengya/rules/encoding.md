# 编码规则 — 柳岸花又明风格实例

## 信息编码密度标准

**核心规则**：每3句话中至少有1句承载>=3层信息。高密度编码是柳岸花又明风格的骨架。

**密度公式**：
```
每3句叙述 >= 1句高密度句（承载3层以上信息）
高密度句 = 表面动作/台词 + 情感暗线 + 人物关系变化 + 时代/社会信息
```

**高密度编码示例**：
- "她把最后一块西瓜让给他。" —— 表面：让西瓜。暗线1：她喜欢他。暗线2：她自己的需求永远排在后面。暗线3：这个动作他上辈子见过一百次但从来没在意过。
- "他说着接过来，咬了一口。操，不甜。" —— 表面：评价西瓜。暗线1：粗口包裹感动。暗线2：假装不在乎。暗线3：他知道她让出来的含义但不敢接。

**低密度句的功能**：低密度句用于节奏呼吸，但不能连续超过3句——连续低密度意味着"注水"。

## 情感物理化的身体出口对照表

> 原作指纹：柳岸花又明的情感表达几乎全部通过"身体反应"完成，不通过心理描写。读者通过角色的身体反应感知情绪。

**核心原则**：不写"他感到XX""她觉得XX"，写"他的手XX""她的眼睛XX"。情感必须有物理出口。

| 情感 | 身体出口 | 强度等级 | 示例 |
|------|---------|---------|------|
| 心动 | 心脏/呼吸 | 轻度：心脏跑了一下；重度：呼吸困难 | "心脏还会跑。上辈子甲方坐对面一排人盯着他汇报方案他眼都不眨。" |
| 紧张 | 手/嘴 | 轻度：手指动了一下；重度：咬嘴唇/手心出汗 | "她把书角折了又折" |
| 难过 | 鼻子/眼睛 | 轻度：鼻子酸了一下；重度：眼眶红了但没哭 | "鼻子有点堵" |
| 尴尬 | 视线/动作 | 轻度：移开目光；重度：找事做/点烟/喝水 | "他低头点烟，点了好几下" |
| 愤怒 | 声音/动作 | 轻度：声音变冷；重度：摔东西/提高音量 | "她咬了他手腕一口" |
| 委屈 | 沉默/退缩 | 轻度：少说一句话；重度：换个座位/走另一条路 | "她低头不说话，把奶茶吸管咬扁了" |

**使用规则**：
1. 每个情感段落至少有1个身体出口
2. 同一个角色在不同情绪下使用不同的身体出口
3. 身体出口的强度随情节递进——越到后面身体反应越明显
4. 禁止直接写情感词（"他很难过""她很感动"），必须替换为身体反应

## 动作信息编码的四要素公式

> 原作指纹：一个看似简单的动作段落，往往同时编码四个层面的信息。

**四要素公式**：
```
动作编码 = 表面动作 + 情感暗线 + 关系状态 + 社会语境
```

**要素拆解**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 表面动作 | 角色在做什么（字面意思） | "他给她买了一瓶水" |
| 情感暗线 | 动作背后的真实情感 | 他注意到她口渴但不会说 |
| 关系状态 | 两人当前的关系阶段 | 还没到可以互相关心的阶段，所以用"随手"掩饰 |
| 社会语境 | 动作发生的社会环境/时代背景 | 2003年小卖部的矿泉水一块五，他不缺这一块五但她在意 |

**编码检验**：
- 把一个动作段落拆开，看它是否同时包含4个要素。如果只有1-2个，说明编码不足，需要补充。
- 把情感暗线抽掉后，这个段落是否仍然"读得出味道"？如果能，说明编码成功——信息已经嵌入动作本身，不需要叙述者额外解释。

## 母题变奏系统

> 原作指纹："你是谁？"在前面几章出现三次——第1章对王梓博说（真不认识），第2章对萧容鱼说（也真不认识），第3章"你他妈又是谁？"（降维打击）。同一个短句，三次含义完全不同。

**母题设计方法**：

| 母题类型 | 设计方式 | 变奏规则 |
|---------|---------|---------|
| 重复问句 | 同一个问题出现>=3次 | 每次答案/语境不同，第三次含义质变 |
| 重复短语 | 主角的口头禅 | 随剧情推进含义质变：无奈→主动→释然 |
| 重复称呼 | 对某人的称呼随关系变化 | 从"学姐"→"名字"→"昵称"，称呼变化=关系变化 |
| 重复物件 | 与虐心线绑定的物品 | 同一物件每次出现承载不同情感（搪瓷杯：勤工俭学道具→等待的证据→离别的信物） |

**使用规则**：
1. 首次出现自然，不强调
2. 第二次出现读者开始注意到重复
3. 第三次出现含义质变，产生强烈的情感冲击或喜剧效果
4. 禁忌：连续两章出现同一个语言母题（间隔>=2章）

**文化嵌入母题**（每3-5章嵌入一个）：
- 歌曲嵌入：引用1-4句歌词 + 角色听到后的反应
- 影视/游戏嵌入：角色提及时代流行文化
- 物品文化嵌入：时代特有物品附带文化记忆
- 禁忌：文化元素必须与时代设定吻合，不能为嵌入而嵌入

**母题变奏检验**：
- 把一个母题从文中抽掉，情感线是否仍然成立？如果成立，说明母题只是装饰而非骨架
- 同一个母题在故事前期和后期的含义是否发生了质变？如果没有，说明没有真正变奏
