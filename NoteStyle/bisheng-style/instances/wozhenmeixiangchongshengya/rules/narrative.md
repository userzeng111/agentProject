# 叙事特化规则 — 柳岸花又明风格实例

---

## 开头100字辨识度规则

> 迭代发现：每章开头100字内必须出现至少一个"柳岸花又明特征标记"——粗口、旁观者废话、或社会人式评价。纯描写式开头（即使写得再好）也缺乏辨识度，读者无法在前100字内确认"这是那个味道"。

**核心原则**：开头100字是读者建立风格预期的窗口。如果前100字读起来像任何人的小说，这章的开头就失败了。

**柳岸花又明特征标记**（开头100字内至少出现1个）：
1. **粗口起手**："妈的""操""狗日的"——直接点燃痞气氛围
2. **旁观者废话**：路人/室友/NPC的吐槽或八卦——制造社会压力感
3. **社会人式评价**：叙述者用前世经验/人情世故评价当前处境——建立重生者视角

**正误对比**：
```
❌ 阳光透过梧桐树叶洒在操场上，新生们三三两两地走着。（纯描写，像任何一部校园小说）
✓ 妈的，九月的太阳跟不要钱似的往头上砸。陈汉升叼着根烟站在宿舍楼下，心想上辈子这种天气他应该在空调房里改方案。（粗口+前世对比，辨识度拉满）

❌ 食堂里人声鼎沸，窗口前排着长长的队伍。（纯场景交代）
✓ 食堂大妈瞅了他一眼："吃啥？"——这语气跟他上辈子见甲方秘书一模一样。（社会人对比+旁观者互动）
```

**禁用**：
- 纯环境描写开头（"天空""阳光""风"等起手）
- 文艺腔感慨开头（"时光""岁月""记忆"等起手）
- 信息说明式开头（"今天是开学的第三天"等平铺直叙）

**例外**：只有当纯描写开头中嵌入了角色极有个性的行为或心理活动时才允许，但必须确保前100字内有口吻辨识度。

## 叙述者人格化规则（替换原"世故长者旁白"）

> 原作指纹：叙述者不是隐形摄像头，是一个有态度、有脾气、有幽默感的"说书人"。他会跳出来评价角色（"陈汉升此时的表情既装逼又欠揍，不过真的是蛮帅"），会替读者吐槽（"老娘也是个狠人，说不伺候就不伺候"），会用过来人的口吻总结（"成人的名利场总是少不了逢场作戏，谁当真谁就是傻瓜"）。

**核心原则**：叙述者是一个有性格的人，不是一个透明的传声筒。他要像一个坐在旁边喝酒的朋友一样，时不时插嘴评价、吐槽、感叹。

**叙述者人格三要素**（每章至少使用2次）：
1. **评价式介入**：叙述者直接评价角色的行为/表情/心态（不是解释，是评价）
   - 原作示例："陈汉升此时的表情既装逼又欠揍，不过真的是蛮帅。"
   - 原作示例："王梓博自己抽的是小心翼翼，但是瞅了瞅陈汉升，他又吭哧吭哧的评价道"
   - 原作示例："老娘也是个狠人，说不伺候就不伺候。"
2. **世故式总结**：用过来人的沧桑口吻，从具体事件提炼一个短句人生感悟（4-20字）
   - 原作示例："人在江湖，身不由己。"
   - 原作示例："成人的名利场总是少不了逢场作戏，谁当真谁就是傻瓜。"
   - 原作示例："事业上成功的男人，既有混不吝的气度，也有厚积爆发的威严。"
3. **反讽式旁白**：用反讽语气拆穿角色或情境
   - 原作示例："失恋又不是失忆"
   - 原作示例："我这样的人重生有什么意思呢？"

**字数规则**：
- 评价式介入：不限长度，可以是一个完整句子（15-40字）
- 世故式总结：4-20字，简短有力
- 反讽式旁白：1句话，10-20字

**禁用**：
- 文艺腔感叹（"岁月如歌""时光荏苒"）
- 解释性复述（重复角色刚用动作表达过的信息）
- 教科书式点评（"这体现了他内心的挣扎"）
- 文学化比喻（"像一首无声的诗""如同秋叶飘零"——这不是柳岸花又明的调性）

## 社会人对比规则

> 迭代发现：叙述者评价时应该多用"前世/成年人"的社会经验做对比，而不是用文学化的比喻。叙述者的世界感来自"见过世面"而非"读过很多书"。

**核心原则**：叙述者的评价素材来源于社会经验、职场见闻、人情世故，而非文学经典或诗意意象。

**正误对比**：
```
❌ 为一件五毛钱的事鞠了一个很重要的躬。（文学化比喻，像散文）
✓ 他上辈子请甲方吃饭那些鞠躬都是假的，但这一躬是真的。（社会人对比，像老油条的感慨）

❌ 那个眼神像一盆凉水浇在心上。（文艺腔）
✓ 那个眼神他熟——上辈子裁员通知发出去的时候，被裁的人都是这个表情。（前世经验对比）

❌ 两个人之间的距离像隔了一条银河。（诗意比喻）
✓ 这种场面他在饭局上见过一百回——一个想走，一个想留，谁都不好意思先开口。（社会阅历总结）
```

**使用方法**：叙述者需要评价/总结时，优先调用以下素材库：
1. 前世的职场经验（甲方、饭局、裁员、项目）
2. 成年人的人情世故（请客、送礼、面子上过得去）
3. 社会现实（钱、生存、阶层、人情债）
4. 普通男人的生活经验（烟、酒、兄弟、姑娘）

## 全知反讽闪现规则（正向示例部分）

> 原作指纹："她以为今天已经是底线，其实只是开头……"——叙事者突然拉远到全知视角，告诉读者角色不知道的事情。这种"你不知道后面有多惨/多甜"的暗示，制造强烈的阅读欲。

**核心原则**：每2-3章，叙事者应插入一次"角色不知道但读者知道/即将知道"的信息闪现。

**四种闪现模板**：

| 类型 | 模板 | 效果 |
|------|------|------|
| 命运暗示 | "他以为XX，其实XX" | 制造悬念+读者优越感 |
| 时间反讽 | "这是他最后一次XX"（或"当时他不知道，这将是XX"） | 给普通行为赋予告别感 |
| 关系预言 | "多年以后他回想起这一幕，才明白XX" | 时间跨度带来的沧桑感 |
| 反向铺垫 | 看似不重要的细节 + 叙事者暗示它以后很重要 | 埋伏笔+制造重读价值 |

**使用规则**：
- **频率**：每2-3章最多1次，不可滥用（滥用=廉价剧透）
- **长度**：1句话，不超过20字，嵌在段落末尾
- **语气**：不是悲情的预告，是过来人的淡然——像翻旧相册时的感慨
- **禁忌**：不能剧透具体情节，只能暗示"这件事比你以为的重要/没那么简单"

**正向示例**：
- "她不知道的是，这把坏伞他后来再也没还回去。"
- "当时他以为这只是一次普通的偶遇。"
- "多年以后他会想起来，她说的'加油'两个字，是这天他收到的最重的礼物。"
