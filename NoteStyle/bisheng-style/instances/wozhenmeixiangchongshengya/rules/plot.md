# 情节规则 — 柳岸花又明风格实例

## 日常松弛节奏

> 原作指纹：前10章几乎没有"大事"——拿通知书、买烟、写同学录、吃西瓜、去外公家、帮外婆晒粮食。全是日常，没有主线，但读者完全不会觉得无聊。

**核心原则**：故事前1/4（约5-8章）不应该有明确的"主线任务"。读者不是来看主角完成任务的，是来看主角"怎么活的"。日常即内容。

**日常松弛三规则**：
1. **无主线规则**：前5章不得出现可量化的"目标/任务/比赛"。章节推动力来自人物互动和关系变化，不来自外部事件
2. **事件密度规则**：每章最多1个"小事件"（食堂吃饭、画线课、图书馆借书），其余全部是人物互动
3. **松弛节奏规则**：每写2章有明确推进的内容后，第3章必须是"纯日常呼吸章"——什么都没发生，但读者更了解角色了

**日常场景池**（前5章优先选用）：
- 吃饭（食堂/宿舍/小馆子）
- 买东西（小卖部/书店/建材市场）
- 睡前闲聊（宿舍夜话、上下铺对话）
- 走路（校园/街道/图书馆走廊）
- 课堂（不是重要课程，是无聊的课上发呆/传纸条/看窗外）
- 天气（下雨躲雨/天热买冰棍/秋风起加衣服）

## 修罗场调度模式

> 原作指纹：柳岸花又明的"修罗场"不是传统意义上的争风吃醋，而是多个角色在同一场景中各自携带不同信息、不同立场、不同情感状态，形成复杂的社交张力场。

**调度三原则**：
1. **信息不对称**：场景中每个角色知道的信息量不同，读者全知或半知
2. **立场多元**：没有纯粹的对错，每个角色的行为都有其逻辑自洽的理由
3. **情绪叠加**：场景中同时存在多个情绪层（搞笑+心疼+紧张），不是单一情绪推进

**修罗场构建模板**：
```
场景设定（日常场所）→ 角色A带着目的1到场 → 角色B带着目的2到场 → 目的1和目的2冲突 → 旁观者制造社会压力 → 主角用痞气/机智化解 → 留下余波
```

## 情节推进靠关系而非事件

> 原作指纹：陈汉升没有"我要考上大学""我要赚一百万"这样的明确目标。情节推进的引擎是人物关系的演变——从陌生人到熟人、从同学到暧昧、从暧昧到纠结。

**推进规则**：
1. 章节的"钩子"不是事件悬念（"他会赢吗？"），而是关系悬念（"她知道了吗？""他会选谁？"）
2. 关系变化是递进的，不允许跳跃（陌生人不能直接变暧昧，必须有中间状态）
3. 每次关系推进必须伴随着一个具体的"事件载体"（一个搪瓷杯、一次食堂吃饭、一场雨）
4. 关系倒退也是推进——"冷战""误解""刻意疏远"都是有效的关系变化

**关系递进层级**：
```
陌生人 → 熟人（记住名字/脸） → 有印象（有共同经历） → 有好感（主动关注对方） → 暧昧（行为超出普通关系） → 纠结（多线冲突）
```

## 社会人对比结构

> 原作指纹：叙述者评价时应该多用"前世/成年人"的社会经验做对比，而不是用文学化的比喻。叙述者的世界感来自"见过世面"而非"读过很多书"。

**对比素材库**（叙述者评价时优先调用）：
1. 前世的职场经验（甲方、饭局、裁员、项目）
2. 成年人的人情世故（请客、送礼、面子上过得去）
3. 社会现实（钱、生存、阶层、人情债）
4. 普通男人的生活经验（烟、酒、兄弟、姑娘）

**对比结构模板**：
```
[当前角色处境/行为] + [前世/社会经验对照] → [叙述者评价]
例："他上辈子请甲方吃饭那些鞠躬都是假的，但这一躬是真的。"
```

**正误对比**：
- 妥协为一件五毛钱的事鞠了一个很重要的躬。（文学化，禁用）
- 正确做法：他上辈子请甲方吃饭那些鞠躬都是假的，但这一躬是真的。（社会人对比）
