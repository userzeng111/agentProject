# 情感特化规则 — 柳岸花又明风格实例

---

## 深情暴露控制规则

> 迭代发现：痞气包裹深情的"包裹层"不能太薄。如果每次温以宁做了让人心疼的事后叙述者都立刻给出温柔解读，包裹层就形同虚设——读者不是被"感动"的，是被叙述者"告知应该感动"的。

**核心原则**：叙述者的职责是用粗口打断深情，不是用温柔解读深情。让读者自己发现深情，叙述者只负责假装没看见。

**控制规则**：
1. **禁止即时解读**：温以宁型角色做了让人心疼的事后，叙述者不得在紧接着的1-2句话内给出温柔/心疼/感慨式解读
2. **必须用粗口/吐槽打断**：叙述者感知到深情后，应该用"妈的""去她的"等粗口或者自嘲式旁白打断，而非感叹"她怎么这么好"
3. **延迟暴露法**：深情可以在后续章节通过"不经意的回忆"暴露，但不能在当下场景中直接解读
4. **读者发现优先**：如果读者能从场景细节自己感受到心疼，叙述者就禁止复述这种心疼

**正误对比**：
```
❌ 她把最后一块西瓜让给他。他忽然觉得心里很酸。（即时解读，包裹层太薄）
✓ 她把最后一块西瓜让给他。"你吃。"他说着接过来，咬了一口。操，不甜。（用粗口打断，深情隐藏在"不甜"的假意评价中）

❌ 温以宁在寒风里等了半个小时，他心里涌上说不出的滋味。（文艺腔暴露）
✓ 温以宁在寒风里站着，鼻子冻得发红。"等很久了？""没有。"妈的，手都僵了还说没有。（粗口+动作细节，让读者自己心疼）
```

**自检法**：写完一段深情场景后，检查叙述者是否在3句话内给出了"心疼/感动/温柔"式评价——如果有，删除，改用粗口或不置可否的短句替代。

**正向示例**：
- 原作："妈的，1米7的身高，就算是根竹竿也很漂亮啊。"（粗口+自嘲审美+间接夸人）
- 原作："可见大学生这个群体多浮躁，宁愿追求一些华而不实的妖艳贱货。"（从自嘲扩展到群体嘲讽）
- 目标："妈的。三十一岁的人了，心脏还会跑。上辈子甲方坐对面一排人盯着他汇报方案他眼都不眨。"（粗口+物理化+降维对比）

## 情感爆发允许规则（修订原9:1克制）

> 原作指纹：萧容鱼直接发怒（"你要是再抽烟，我就去告诉你妈"）、咬陈汉升手腕、王梓博骂"狗男女"。角色不是一直克制的，他们有真实的情绪爆发。

**核心原则**：克制是主基调（约70%），但每4-5章必须安排一次角色"绷不住"的情绪爆发——不是大哭大闹，而是真实的人在压力下失控的瞬间。

**克制vs爆发比例：7:3**（从原9:1下调）

**爆发类型**：

| 类型 | 表现方式 | 触发条件 |
|------|---------|---------|
| 言语爆发 | 突然提高音量/说出平时不会说的话 | 被误解、被看穿、被逼迫 |
| 物理爆发 | 打/推/咬/摔东西 | 极度愤怒或极度委屈 |
| 情绪泄露 | 眼眶突然红了/声音突然哽住/手开始抖 | 隐忍到极限 |
| 行为反常 | 做了完全不符合性格的事 | 在意的人受到威胁 |

**使用规则**：
- 爆发后必须有"收"——角色意识到自己失态后的反应（沉默/转头/离开）
- 温和型角色（如温以宁类）的爆发更应该用"反常行为"而非大吵大闹
- 爆发不等于吵架——最高级的爆发是"沉默比吵架更重"
- **禁忌**：爆发后不能立刻和好，必须留有情绪余波

## 虐心层四大引擎

**核心原则**：虐心不是"让角色受苦"，是"让读者比角色更早看到即将到来的遗憾，却无法阻止"。

**四大虐心引擎**：

| 引擎 | 原理 | 关键写法 | 引爆时机 |
|------|------|---------|---------|
| 信息差 | A知道的B不知道，读者全知 | 用"物"传递差（搪瓷杯、便签纸），不用"话" | 一方即将做出不可挽回的行动 |
| 自卑退缩 | 因自卑而主动放弃即将到手的东西 | 微小动作——换个座位、少说一句话、走另一条路 | 看到喜欢的人和"更配"的人在一起 |
| 隐忍不对等 | 一方付出远多于另一方知道的部分 | 用"等待"和"代替"——等人、等水凉了再接一杯 | 付出变成习惯，习惯变成理所当然 |
| 选择亏欠 | 在两个都重要的人之间做选择 | 不写纠结，写"果断选择后的那个回头" | 被选择者发现了未被选择者的付出 |

**虐心节奏控制**：
- 每3-4章安排一个虐心微节点（一个细节/一句话/一个小动作）
- 每7-8章安排一个虐心小高潮（一个场景/一段内心戏/一次错过）
- 每15-20章安排一个虐心大爆发（表白被误解/信息差引爆/被迫选择）
- 虐心不能连续超过两章，中间必须用甜蜜/搞笑/温馨层做呼吸间隔

**虐心层的"物"系统**：为每条虐心线绑定一个"物"，用物代替语言表达情感——物不变，情感在变。同一个搪瓷杯，第一次出现是"勤工俭学"的道具，第十次出现是"等了一个下午"的证据。

**虐心层禁忌**：
1. 不写角色"哭"——写"眼睛酸了一下""鼻子有点堵"
2. 不写角色"说出口"——写"张了张嘴，什么都没说"
3. 不写"大吵一架"——写"沉默比吵架更重"
4. 不写"我爱你但我要离开你"——写"我走这条路你走那条路，我们都没有回头"
5. 虐心的最高境界是"读者先于角色崩溃"
