# 语言特化规则 — 柳岸花又明风格实例

---

## 主角内心独白口吻规则（痞气层）

> 原作核心指纹：陈汉升的内心独白永远带着一层粗口/俚语/自嘲——他骂骂咧咧地做深情的事。

**核心原则**：主角的内心独白必须有两层——**表面是粗口/吐槽/自嘲，底层是真实情感**。绝不允许"干净"的深情。

**口吻三要素**（每段内心独白至少包含1个）：
1. **粗口/俚语触发器**：在情感涌上来的瞬间，先用"妈的""操""狗日的"引爆，再写情感
2. **自我拆穿**：说完真心话后立即自嘲一句，暴露自己的虚伪/算计/不好意思
3. **降维对比**：用前世/成年人的标准嘲笑自己此刻的幼稚反应

**口吻模板**：
```
[粗口触发] + [真实感受的物理化描述] + [自我拆穿]
例："妈的，被五枚一毛的硬币搞得睡不着觉。上辈子管过上亿的项目眼都不眨。"
```

**禁用清单**：
- 纯净的深情独白（"他心里涌起一股暖流"→ 直接删除）
- 文艺腔感慨（"有些画面让你觉得世界是对的"→ 改为"妈的，一盆破花有什么好看的"）
- 客观冷静的自我分析（"他分析了一下自己的情感状态"→ 改为用粗口打破理性）
- **裸露金句**（"人生最大的遗憾不是做错了什么，是没来得及做什么"→ 改为"妈的，活了两辈子才想明白——你遗憾的从来不是做错了什么，是你他妈的没来得及做什么"）
- **总结性感慨**（"有些味道，只存在于特定的时间"→ 删除，让对比本身传递信息，不要帮读者总结）

**终极比例规则**：
- **粗口:干净深情 = 2:1**（每2次粗口包装的深情，最多允许1次不带粗口的感慨）
- 如果一段深感情慨没有粗口/自嘲包裹，必须在前面加一句降温（自嘲、粗口或"说出来矫情"式否定）
- **自检法**：写完一章后，搜索所有"有些XX""人生XX""这大概就是XX"式金句——每找到一处，检查前面是否有粗口/自嘲。没有的必须加上。

## 方言/俚语/时代口语规则

> 原作指纹：角色对话充满方言味和时代口语——"搞点水喝喝""婶子夸我长得俊""OJBK""舔狗""逼逼赖赖"。叙述语言也不是标准普通话，而是带着口音的"嘴里跑火车"式表达。

**核心原则**：角色的语言必须"有味儿"，不能是标准普通话AI生成体。每个角色应该有自己的语言口音/俚语习惯。

**三层语言体系**：

| 层级 | 角色 | 语言特征 | 示例 |
|------|------|---------|------|
| 粗口层 | 主角+亲密配角 | 粗口/俚语自由使用 | "狗日的""妈的""老子""操" |
| 方言层 | 家乡/地方角色 | 方言词汇+方言语序 | "搞点水喝喝""咋""啥""中不中" |
| 时代层 | 所有人 | 时代流行语 | 2003年："牛B""酷毙了""帅呆了""铁子""哥们儿" |

**角色语言指纹规则**（每人至少1个口癖）：
- 主角：粗口+自嘲口吻（"妈的""操""来都来了"）
- 话痨配角：夸张口头禅（"卧槽""嗷""嘿嘿"）
- 老一辈：方言短句（"中""咋了""老实说"）
- 女主A：直接/犀利（"切""呵""没意思"）
- 女主B：极简/犹豫（"嗯""...好"）用省略号表达迟疑

**叙述语言也必须带口语味**：
- ❌ "赵益铭从上铺跳下来" → ✓ "赵益铭嗖地窜下来了"
- ❌ "他感到不满" → ✓ "他心里骂了一句"
- ❌ "刘畅表示赞同" → ✓ "刘畅从被窝里哼了一声"

## 自造词/专属称谓系统

> 原作指纹："静雕"（自造复合词）、"宝藏女孩"（专属称谓）、"三年血赚无期不亏"（口语比喻签名）。这些词让读者一眼认出作者是谁。

**核心规则**：每个故事必须创造2-3个自造词或专属称谓，它们是文风的"音频指纹"。

**造词方法**：

| 造词类型 | 方法 | 示例 |
|---------|------|------|
| 自造复合词 | 两个不常搭配的字/词强行组合，产生陌生化效果 | "静雕"（静止+雕塑） |
| 专属称谓 | 主角对重要角色的内心命名，必须包含评价/情感 | "宝藏女孩"（珍贵+不被发现） |
| 口语比喻签名 | 用非文学领域（游戏/网络/职业）的术语比喻情感 | "三年血赚无期不亏"（游戏术语→人生观） |
| 反常规搭配 | 用一个不搭的形容词修饰名词，制造认知反差 | "掩耳盗铃的划清界线"（成语+自嘲式旁白） |

**使用规则**：
1. **自造词首次出现**：必须在主角内心独白中诞生，用痞气口吻"命名"
2. **称谓建立后**：只在主角内心独白中使用，角色对话中不出现（它是内心特权）
3. **口语比喻**：必须在文学化比喻后紧跟一个口语/网络比喻，制造语气切换
4. **分布密度**：自造词/称谓每3-5章使用一次，不可每章都用（用多了贬值）

**造词检验**：
- 把这个词拿出来给没看过原文的人，他能不能感受到"这是一种独特的表达"？
- 这个词是否只属于这个角色？换一个角色用这个词是否违和？

## 极口语幽默配方

**反差幽默（重生者降维视角）**：
- 公式：用[前世身份]的标准评价[当前处境]，制造荒谬对比
- 关键：越一本正经越搞笑
- 示例骨架：「按照[专业/身份]的标准，[当前处境]实在[荒谬评价]」

**痞气幽默（宿舍/兄弟场景）**：
- 公式：粗口 + 荒谬逻辑，威胁内容越离谱越好笑
- 必须包含粗口（"老子""狗日的""妈的"）
- 示例骨架：「你[不做A]，老子就[极度离谱的B]」

**自嘲幽默（内心独白）**：
- 公式：先说事实 → 再用一句话拆穿自己的虚伪/算计
- 关键：自嘲越狠越真实，是主角"安全阀"
- 示例骨架：「[表面行为]，说白了就是[真实目的]」

**冷面幽默（社交/暧昧场景）**：
- 公式：用极度认真的态度说极度荒谬的话
- 关键：表情越正经效果越好
