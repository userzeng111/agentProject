- 新增 `/p/[projectId]`，先复用现有 `TaskRunClient` 并通过 route param 传入 `taskId`。
- 更新 `task-routes.ts` 与 E2E 路由抽象，让新入口生成 `/new` 与 `/p/{projectId}`。
- 旧 `/create` 与 `/tasks?id=...` 先保持兼容跳转。
- 暂不纳入完整三步向导、审核页左右分屏、结果阅读器、移动端底部 Tab 与大组件拆分。

## 推荐测试优先级

- 先补 `apps/web/src/lib/task-routes.test.mjs`，直接导入真实 helper，验证新 canonical 路由。
- 新增/调整 E2E，覆盖 `/new` 可达、创建成功进入 `/p/{id}`、旧入口兼容跳转。
- 实现后至少运行相关前端单测、路由迁移 E2E、lint 与 build；若触发静态导出限制，先在测试中暴露并收敛处理方案。
