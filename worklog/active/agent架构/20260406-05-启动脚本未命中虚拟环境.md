# 启动脚本未命中虚拟环境

## 用户原始诉求
- 执行 `./start-backend-tunnel.sh` 后，后端启动失败，提示 `/usr/bin/python3: No module named uvicorn`

## 当前已知上下文
- 用户在仓库根目录执行了 `./start-backend-tunnel.sh`
- 脚本输出的后端命令为 `python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload`
- 当前系统解释器为 `/usr/bin/python3`
- 后端项目位于 `apps/agent-runtime`

## 当前状态
- 已创建问题记录
- 正在分析脚本为什么没有使用后端项目虚拟环境

## 本轮实现进展
- 已确认根因：
  - `start-backend-tunnel.sh` 的 `detect_python()` 原先优先选择系统 `python3`
  - 当前机器上的系统解释器为 `/usr/bin/python3`，未安装 `uvicorn`
  - 后端实际可用解释器位于 `apps/agent-runtime/.venv/bin/python`
- 已修改脚本：
  - `detect_python()` 现在优先返回 `apps/agent-runtime/.venv/bin/python`
  - 仅当项目虚拟环境不存在时，才回退到系统 `python3` / `python`

## 本轮验证记录
- 修复前红灯验证：
  - `./start-backend-tunnel.sh --dry-run`
  - 输出后端命令为 `python3 -m uvicorn ...`
  - 断言 `.venv/bin/python` 失败
- 修复后 dry-run 验证：
  - `./start-backend-tunnel.sh --dry-run`
  - 输出后端命令为 `/home/user01/WorkSpace/AgentProject/apps/agent-runtime/.venv/bin/python -m uvicorn ...`
- 修复后真实启动验证：
  - `timeout 10s ./start-backend-tunnel.sh`
  - 后端成功启动并通过健康检查
  - Tunnel 成功启动并注册连接
  - 超时退出后 `8000` 端口无残留监听
