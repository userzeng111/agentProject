# 2026-04-17 补充分析（二）：原小说专用 skill 的事实入口与映射边界
- 事实入口已进一步拆分为三层：
  - 源头入口：`NoteStyle/bisheng-style/SKILL.md` 定义了原始“笔生”小说风格 skill 的意图触发、实例加载原则、创作/蒸馏双模式与质量协议；`engine/loading-mechanism.md` 明确其原生流程是“意图识别 -> registry 匹配 -> manifest/rules 加载 -> 引擎/实例规则合并”。
  - 当前仓库运行时入口：`apps/agent-runtime/app/style_profiles/service.py` 把 `NoteStyle/bisheng-style` 当成实例资料目录，固定读取 `instances/registry.yaml`、各实例 `manifest.yaml`、`rules/*.md`，并压缩成 `compiled_summary`；`apps/agent-runtime/app/main.py` 在启动时实例化 `StyleProfileService`，`apps/agent-runtime/app/api/routes.py` 通过 `GET /api/style-profiles` 暴露实例列表。
  - 任务流入口：`apps/web/src/features/task-create/create-task-client.tsx` 仅在 `style_remix` 模式下暴露 `style_profile_id` 选择；`apps/agent-runtime/app/graph/main_graph.py` 在 `mode == style_remix` 时把实例编译结果写入 `normalized_spec.style_guidance`；`apps/agent-runtime/app/llm/story_engine.py` 再把 `style_guidance` 作为 `style_requirements` 注入大纲、章节、章节修订 prompt。
- 与 bisheng-style 同构、可抽象复用的能力：
  - 注册发现：`registry.yaml` 驱动的实例发现、状态过滤、路径解析。
  - 元数据装配：`manifest.yaml` + 注册表字段合并，形成统一 profile 元信息。
  - 规则分维度编译：把多文件规则目录压缩成运行时可注入摘要。
  - 规则优先级模型：实例规则优先、引擎兜底、不叠加，这一原则与主项目现有 `style_guidance` 组装方式同构。
  - 模式级注入：前端模式控制 -> 后端 `normalized_spec` -> prompt 注入，这一链路本质上是“资料型 skill 注入器”。
- 明确不应误判为同一体系的部分：
  - `NoteStyle/bisheng-style/SKILL.md` 是 markdown 型方法论 skill；主项目 `SkillLoader` 只加载 `apps/agent-runtime/app/agents/skills/<agent>/*.yaml`。二者格式、加载位置、执行器都不同。
  - 当前仓库并不存在实际生效的 `story_engine/*.yaml` 外置 skill；`StoryEngine` 虽保留 Skill YAML fallback 入口，但当前真实运行仍主要依赖内置 `ChatPromptTemplate`。
- 必须保留为小说专用、不要泛化到其他风格的部分：
  - `style_remix` 任务模式本身。它不是普通“写作风格”字段，而是“基于既有小说实例做风格复写”的业务语义。
  - `bisheng-style` 的九类小说规则维度：`language / narrative / character / plot / emotion / scene / dialogue / constraints / encoding`。这些维度高度绑定小说创作，不适合直接抽象成任意内容风格协议。
  - 实例元数据中的小说语义字段：`source_novel`、`source_author`、`genre`、`fidelity_score`、`trigger_keywords`。这些字段服务于“原作/作者风格实例”匹配与解释，不是通用样式系统字段。
  - 原 skill 中的创作协议：故事骨架、卷纲/章纲、场景卡、章节四段式、9 项创作自检、7 项失真审校、蒸馏模式。这些不是一般 style profile 的公共职责，而是小说生产方法论。
  - “仿写/复刻指定小说风格但不直接复刻原文”的约束语义。这是当前项目面向小说任务链的合规边界，泛化后容易把风格 profile 错当成通用文案皮肤。
