## 推荐设计

### 覆盖层级

1. **Playwright API 基线层**
   - 使用 `@playwright/test` 的 `request` fixture 覆盖轻量 API。
   - 覆盖：health、models、dashboard、style-profiles、settings/rag、settings/protocols 只读、archive list/detail、task create/read/workspace/supervisor/chapters/artifacts、file-text invalid、任务文件非法路径、CORS 本地 origin。
   - 对创建的测试任务执行清理，避免 tasklog 持续膨胀。

2. **Playwright 页面真实后端层**
   - 自动拉起或复用 FastAPI + Next dev server。
   - 覆盖页面可达与真实 DOM：`/`、`/create`、`/tasks?id=<created>`、`/archive`、`/archive/detail`、`/settings`。
   - 使用 API setup 创建 `created` 与 `sources_ingested` 任务，不触发 LLM。
   - 覆盖上次提交的调试 Tab 真实页面断言。

3. **Playwright fixture UI 分支层**
   - 对难以低成本构造的状态分支使用 `page.route` mock 后端响应。
   - 覆盖：planning/drafting/assembling、waiting_outline_review master、waiting_outline_review chapter_batches、ready_for_batch、waiting_chapter_review、waiting_verification_review、waiting_manual_action 可恢复、failed、cancelled、completed、archive detail、chat SSE error/chunk。
   - 目标是保证页面所有分支渲染、按钮状态、跳转、弹窗、敏感内容保护都被覆盖。

4. **慢测/手动触发层**
   - 不纳入默认 `test:e2e`。
   - 包含真实 `run/resume/continue/recover` 生成链路、真实 chat stream/completions、RAG rebuild、dynamic orchestrate/compare。
   - 通过单独命令或环境变量启用，避免默认自动化污染数据或受网关波动影响。

### 默认不纳入 E2E 的内容

- 真实 LLM 生成完整小说流程。
- RAG 全量重建。
- 精确断言聊天模型输出文本。
- 下载/复制正文全文的内容一致性。
- 原始 prompt、raw response、RAG 命中文本或章节正文展示。

这些内容由既有后端测试、前端纯函数测试、API smoke 或后续慢测补位。
