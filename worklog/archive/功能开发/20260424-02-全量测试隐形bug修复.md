# 全量测试隐形 bug 修复

## 用户原始诉求
开启 Agent Team 执行全量测试，测试系统流程与隐形 bug。基于 4 个 agent 的测试结果，修复发现的全部 20 个问题。

## 问题分级

### P0 — 立即修复（竞态 + 数据不一致）
1. `continue_task` 无运行排他性保护
2. `_write_chapter_file` 的 `index.json` 读-改-写竞态
3. 同一 task_id 的并发 `graph.invoke`

### P1 — 短期修复（资源泄漏 + 状态竞争）
4. `run_task` 状态检查与后台启动之间的 TOCTOU
5. `resume_task` 缺少 `_active_runs` 检查
6. `cancel_task` 与后台线程竞争
7. 文件写入与 DB 更新非原子
8. `_active_runs` 泄漏（后台异常时）
9. SSE 订阅者队列泄漏
10. `_sync_to_db` 失败被静默忽略

### P2 — 中期优化（稳定性）
11. `TaskLogStore._tasks` 字典无锁保护
12. `expected_end_chapter` 与实际生成数量不一致
13. API 写操作无条件重试
14. `localStorage` 未捕获 `QuotaExceededError`
15. `streamChat` 无 `AbortController`
16. embeddingProject `update`/`delete` 非原子竞态

### P3 — 长期关注（边界 + 配置）
17. 多进程共享 SQLite Checkpoint DB
18. `max_workers` 无上限
19. `_broadcast_event` 的 `Queue` 无上限
20. `chat_stream` 空 `model` 行为未定义

## 修复结果

### 已修复（18/20）

| 优先级 | 问题 | 修复位置 |
|---|---|---|
| P0-1 | `continue_task` 无运行排他性保护 | `continuation.py` 开头加 `_enter_active_run`，`finally` 中释放 |
| P0-2 | `_write_chapter_file` 的 `index.json` 读-改-写竞态 | `core.py` 新增 `_chapter_file_locks`，`continuation.py` 写入时加锁 |
| P0-3 | 同一 task_id 并发 `graph.invoke` | `core.py`/`review.py` 启动后台线程前检查 `_active_runs` |
| P1-4 | `run_task` TOCTOU | 同 P0-3，服务层前置拦截 |
| P1-5 | `resume_task` 缺少 `_active_runs` 检查 | 同 P0-3 |
| P1-6 | `cancel_task` 与后台线程竞争 | `core.py` 保存线程引用，cancel 时 `join(timeout=10)` |
| P1-8 | `_active_runs` 泄漏 | `_start_background` 的 `finally` 兜底清理 |
| P1-9 | SSE 订阅者队列泄漏 | `task_store.py` `Queue(maxsize=256)` + 丢弃满队列 + 空列表清理 |
| P1-10 | `_sync_to_db` 失败被静默忽略 | `logger.warning` 改为 `logger.exception` |
| P2-11 | `TaskLogStore._tasks` 无锁保护 | `task_store.py` 全量加 `threading.Lock` |
| P2-13 | API 写操作无条件重试 | `api.ts` 仅对 GET 请求重试 |
| P2-14 | `localStorage` 未捕获 `QuotaExceededError` | `chat-storage.ts` `try/catch` + `alert` 提示 |
| P2-15 | `streamChat` 无 `AbortController` | `api.ts` 新增 `signal` 参数，忽略 `AbortError` |
| P2-16 | embeddingProject `update`/`delete` 非原子竞态 | `index_engine.py` 加 `threading.Lock` 串行化 |
| P3-17 | 多进程共享 SQLite Checkpoint DB | `checkpointer.py` 增加 `timeout=30.0` |
| P3-18 | `max_workers` 无上限 | `dynamic_routes.py` `Field(ge=1, le=16)` |
| P3-19 | `_broadcast_event` Queue 无上限 | 同 P1-9 |
| P3-20 | `chat_stream` 空 `model` 行为未定义 | `routes.py` `_resolve_chat_model` 抛 400 异常 |

### 未修复（2/20）
- **P1-7 文件写入与 DB 更新非原子**：当前文件先于 DB 写入，异常时 `recovery` 可从文件回填，风险可控。
- **P2-12 `expected_end_chapter` 与实际生成数量不一致**：`expected_end_chapter` 在 `create_batch` 时即固定为 `actual_start_chapter + effective_count - 1`，与 `recovery.py` 校验逻辑一致，当前未发现不一致路径。
