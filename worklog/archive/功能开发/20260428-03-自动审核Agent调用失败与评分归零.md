# 自动审核 Agent 调用失败与评分归零

## 问题标题
自动审核动态 Agent 系统：JSON 解析失败 + 评分全为 0

## 用户原始诉求
走一次全自动流程，自动审核功能。当前 agent 调用存在问题：
- 第 5 轮，1 主 Agent + 4 子 Agent + 1 综合裁决
- 5 个失败，历史 4 轮，评分 0 分，子执行 0/5 完成

## 当前状态
已修复，已归档。本轮修复覆盖 JSON 解析失败、评分字段缺失、resume API 400、综合 Agent 字段名不兼容、子 Agent 变量名不匹配导致空内容等 6 个根因。

## 现象分析

### 现象1：Agent 执行失败（JSON 解析错误）
日志样本（18:18）：
```
Agent 执行失败: 结构分析师，错误: '"score"'
Agent 执行失败: 综合决策专家，错误: '\n  "overall_score"'
动态编排完成 — 创建: 5，成功: 0，失败: 5
```

### 现象2：Agent 执行"成功"但评分全为 0.0
日志样本（18:19-18:20）：
```
Agent 执行完成: 结构分析师，评分: 0.0，耗时: 15775ms
Agent 执行完成: 综合决策专家，评分: 0.0，耗时: 4302ms
动态编排完成 — 创建: 6，成功: 6，失败: 0，评分: 0.0
```

模型使用: `MiniMax-M2.7-highspeed`

## 根因分析

### 根因1：system_prompt 缺少 JSON 格式强制要求
`AgentFactory.execute_agent()` 构建的消息：
```python
messages = [
    {"role": "system", "content": bp.system_prompt},  # MasterAgent 生成，不保证包含 JSON 要求
    {"role": "user", "content": user_prompt},
]
```

与 `AutoReviewManager._call_llm()` 对比：
```python
messages = [
    {"role": "system", "content": "你是一个中文小说质量审核专家，请严格返回 JSON 格式的审核结果，不要输出额外解释。"},
    {"role": "user", "content": prompt},
]
```

动态系统的 `bp.system_prompt` 由 MasterAgent 根据 `MASTER_BLUEPRINT_PROMPT` 生成，prompt 中仅示例性要求 `"system_prompt": "该角色的系统 prompt，包含职责定义和评分标准（0-100）"`，**未强制要求包含 JSON 输出格式**。导致模型有时返回纯文本而非 JSON，触发 JSON 解析失败。

### 根因2：评分字段缺失时无 fallback
`AgentFactory.execute_agent()` 中评分提取逻辑：
```python
score = 0.0
for score_key in ("score", "total_score", "overall_score", "weighted_score"):
    if score_key in response and response[score_key] is not None:
        try:
            score = float(response[score_key])
            break
        except (ValueError, TypeError):
            pass
```

当模型返回的 JSON 中**缺少 score 字段**（模型未按要求评分），score 保持默认值 0.0，没有任何警告日志。

### 根因3：MasterAgent 生成的 user_prompt_template 未明确要求 score 字段
MasterAgent 生成的 prompt 可能只要求模型"分析"而非"评分"，导致模型返回的 JSON 包含 analysis/issues/warnings 但缺少 score。

## 修复方案

1. **AgentFactory.execute_agent()**：当 `output_format == "json"` 时，自动在 user_prompt 末尾追加 JSON 输出要求和评分字段强制要求，确保无论 MasterAgent 生成什么 prompt，模型都知道必须返回 score
2. **AgentFactory.execute_agent()**：当 JSON 解析成功但缺少 score 字段时，记录警告日志，并尝试从 reasoning 文本中提取数值评分作为 fallback
3. **AgentFactory.execute_agent()**：当 Agent 执行失败时，记录 raw_response 内容（前 500 字符）以便调试
4. **MasterAgent prompt**：增强 `MASTER_BLUEPRINT_PROMPT`，明确要求生成的 `system_prompt` 必须包含"返回严格 JSON 格式"的指令

## 根因4：resume API 400 Bad Request（章节审核批次记录缺失）
`review.py` 的 `resume_task` 在处理 `chapter_pair_review` 时要求必须有 `active_batch`，但某些任务（如旧流程或异常流程）在 `waiting_chapter_review` 状态下数据库中缺少 `novel_generation_batch` 记录，导致用户点击通过/驳回时直接报 400。

## 根因5：综合 Agent 字段名不兼容
日志显示综合决策专家返回的 JSON 中使用的字段名为 `final_score`、`synthesis_score`，但 `factory.py` 的评分提取逻辑只识别 `score` / `total_score` / `overall_score` / `weighted_score`，导致综合 Agent 评分被记为 0.0，进而 `overall_score` 被带崩为 0。

## 根因6：子 Agent 变量名不匹配导致收到空内容
MasterAgent 动态生成 `user_prompt_template` 时可能使用 `{chapter_content}`、`{chapters}` 等变量名，而系统传入上下文的键名为 `current_chapters_text`。`render_prompt` 找不到匹配变量时，子 Agent 收到的 prompt 中章节正文部分只剩 MasterAgent 自行构造的占位符（如"【第1章内容】"），导致子 Agent 报"未提供实际内容"。

## 修复方案（补充）
5. **`app/application/task_service/review.py`**：当 `get_active_batch` 返回 None 时，自动根据 `pending_review.chapter_pair` 重建批次记录，不再直接报错。
6. **`app/agents/dynamic/factory.py`**：评分字段兼容列表增加 `final_score`、`synthesis_score`。
7. **`app/agents/dynamic/orchestrator.py`**：
   - `_calculate_overall_score`：当综合 Agent 返回 0 分但子 Agent 有正常分数时，自动回退到子 Agent 加权平均。
   - `_execute_dag`：为 `current_chapters_text` 提供多个常见变量名别名（`chapter_content`、`chapters`、`content`、`text`、`chapter_text`、`chapter_pair`），增加匹配概率。
8. **`app/agents/dynamic/prompts.py`**：增强 `MASTER_BLUEPRINT_PROMPT`，明确要求分析型 Agent 的模板中**必须包含 `{current_chapters_text}`**，不得自行构造占位符。
