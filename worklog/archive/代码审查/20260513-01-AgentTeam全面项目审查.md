## P0 问题清单（必须立即修复）

### 安全 & 运维（3 个）
1. **API Key 硬编码泄露**：`apps/agent-runtime/.env` 含真实 Key，且 git 历史（commit 088e936e）中已泄露
2. **CORS 过度宽松**：`main.py` 允许任意 IP 带凭证访问，存在 CSRF 风险
3. **文件接口路径遍历**：`routes.py` 文件读取未充分过滤 `../`，可读取任意文件

### 后端 API & 状态机（4 个）
4. **SSE 流永久挂起**：`event_stream` 中 `queue.get()` 无任务终止检测，客户端永久等待
5. **`cancel_task` 恢复状态被错误覆盖**：`blocked_from_status` 保存时机不当，恢复后进入错误阶段
6. **`continue_task` 异常后章节计数不一致**：部分写入章节后异常，`completed_chapter_count` 未更新
7. **`graph` setter None 值风险**：`workflow_engine = None` 时后续调用抛 AttributeError

### LLM 工作流 & 网关（3 个）
8. **并行草稿 conversation_history 丢失**：`_should_parallel_chapter_draft=True` 时传入空列表，上下文断裂
9. **流式中断无恢复**：`StreamInterruptedAfterStartError` 直接抛出，无 fallback 机制
10. **异步客户端无锁**：`_get_async_client()` 无锁保护，高并发可能泄漏连接

### RAG & 数据层（5 个）
11. **RAG 重建非原子**：先删旧索引再构建，崩溃后知识库不可用
12. **文件写入非原子**：`task_store.py` 直接 `path.write_text()`，崩溃后文件可能为空
13. **章节文件写入非原子**：`continuation.py` 直接写入 `.md/.json`，无原子保护
14. **数据库事务无回滚**：`get_session()` 无上下文管理器，异常时事务悬挂
15. **SQLite 无 busy_timeout**：并发写入触发 `DATABASE LOCKED`

### 前端体验（3 个）
16. **SSE 事件源组件卸载泄漏**：`task-run-client.tsx` 重连定时器未清理，内存泄漏
17. **聊天 fetch 未中止**：`chat-client.tsx` 流式输出期间离开页面，请求继续运行
18. **删除任务整页刷新**：`window.location.href = "/"` 导致 SPA 状态丢失

## P1 问题精选（建议尽快修复）

- 审核通过后 LangGraph checkpoint 与数据库状态不一致
- Prompt 注入风险：用户输入直接嵌入 prompt 无转义
- 缓存 key 未包含 max_tokens，导致缓存污染
- 全站无速率限制，存在 DoS 风险
- 前端 Markdown 渲染未消毒，存在 XSS 风险
- RAG 检索无相关性阈值、无去重
- 删除任务后数据库关联记录孤立
- 归档操作非原子化
- 错误处理泄露内部异常详情
