## 2026-07-06 审查修复记录

审查发现并修复：

1. `test_performance_observability.py` 在模块导入时全局执行 `set_perf_log_enabled(True)`，会污染同一 pytest 进程中的性能日志默认开关。
   - 已改为 autouse fixture：每个测试前保存旧值，测试中启用，测试后恢复。
   - 已新增默认关闭测试，覆盖 `log_performance()` 与 `performance_span()` 在关闭状态下不输出日志。
2. `request_flow_var` 使用 `ContextVar[list]` 且默认值为 `[]`，会导致独立 context 共享同一个可变列表。
   - 已改为 `ContextVar[list[str] | None]`，默认 `None`。
   - `push_request_flow()` 在无当前 flow 时创建当前 context 专属 list。
3. `TracingMiddleware` 请求结束后只 reset `request_id_var`，未恢复 request flow。
   - 已使用 `flow_token = request_flow_var.set([request.method])` 初始化每个请求独立 flow，并在 finally 中 reset。
   - 为兼容 FastAPI 同步 handler 线程池，保留每个请求独立 list 对象，让 handler 内的 `push_request_flow()` 能被 middleware 汇总到 `flow=`。
4. 新增 active 文档未登记到 `worklog/index.md`。
   - 已补充当前问题索引条目。

新增验证覆盖：

- 性能日志默认关闭时不输出。
- 独立 `contextvars.Context()` 不共享 request flow。
- `TracingMiddleware` 输出 `GET→handler` 调用链，并在请求结束后恢复外层 flow。
