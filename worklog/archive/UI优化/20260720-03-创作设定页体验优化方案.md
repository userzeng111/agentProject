# 创作设定页体验优化方案

## 用户原始诉求

“创作页面也需要针对他的 UI 和 UX 进行调整优化，你去设计一下优化方案”。

## 当前状态

已完成并经用户确认收口归档。范围为 `/new/` 创作设定/创建任务页面；已完成三阶段工作台、准备度反馈与响应式侧栏/底栏实现，并通过自动化回归与生产构建。2026-07-21 已按用户要求启动本地前后端，未执行额外接口烟测。

## 设计目标

- 在桌面端以工作台布局承载长表单，避免整页纵向滚动。
- 将任务设定拆为清晰的阶段，降低一次性决策负担。
- 持续提供可理解的创作摘要、模型状态与提交前校验。
- 保留现有任务类型、篇幅、模型、参考素材、风格、RAG 与高级参数的全部语义。

## 审查结论

- 实际页面为 `/new/`，`/create/` 仅为兼容跳转入口。
- 当前三张长表单卡会同时渲染，步骤导航只作锚点跳转，没有当前态与完成态；首屏也将创意提示词放在模型和规模配置之后。
- `1280px` 左右的三栏会挤压中央编辑宽度；移动与中等宽度又隐藏步骤和摘要，创建状态反馈不足。
- RAG 未就绪在提交处理时会被拦截，却未纳入按钮就绪判断，用户可能在点击创建后才看到顶部错误。
- 模型能力明细默认展开、双重卡片内边距、窄屏自动审核横排、直接重置长文本，都会放大表单的操作负担。

## 拟定方案

### 信息架构

改为“单阶段创作工作台”，字段仍使用现有 `payload` 保留，允许自由前后跳转而不丢失输入：

1. **故事核心**：创意提示词优先，随后是创作类型、题材、标题倾向与目标读者。
2. **参考与边界**：同人/风格复刻时优先显示所需参考实例；补充风格、禁忌与参考文本采用按需展开的补充设定。
3. **篇幅与执行**：篇幅、章节数、单章字数、创作模型、自动审核和审核模型；模型能力明细折叠保留。

### 页面布局

```text
≥1440px  步骤与完成态 | 当前阶段的中央编辑区（唯一纵向滚动） | 准备度清单与创建
960–1439px 步骤侧栏 | 当前阶段的中央编辑区（唯一纵向滚动） | 顶部紧凑摘要
600–959px  紧凑横向步骤条 | 当前阶段编辑区 | 底部操作栏
<600px     紧凑三步进度 | 当前阶段编辑区 | 安全区底部“缺少 N 项 / 创建”
```

- 三栏仅在足够宽度出现，避免中栏被双侧栏挤压；中窄屏保留步骤导航而非同时隐藏所有上下文。
- 移动端底部主操作至少 44px，自动审核改为纵向阅读；卡片由内容区统一控制内边距，避免双重留白压缩输入框。
- 延续现有米纸背景、绿色主操作与中文宋体标题，不引入与产品风格割裂的大色块。

### 就绪与反馈

- 右侧/底部“创建准备度”以可操作清单持续显示：提示词、创作模型、章节数、条件式参考实例、固定审核模型和 RAG 状态；缺项可直接定位相应阶段和字段。
- RAG 不可用时主操作改为“前往知识库同步”，同时保留后端提交保护，避免前后端语义不一致。
- 模型能力、风格实例详情、补充设定采用可访问折叠区；已填写时显示简短摘要。
- 合并为一个带二次确认的重置入口；重试预填显示完成提示；创建与文件上传展示明确的分阶段状态，上传失败时说明任务已经创建，避免重复创建。

## 不改变的范围

- 不修改任务创建 API、模型兼容校验、RAG 后端保护、创作类型/风格实例的条件逻辑，或重试预填和上传的业务语义。
- 不恢复整页纵向滚动；保持中央工作区为唯一的主要滚动区域。

## 验收计划

- 覆盖 375、768、1024、1440 宽度：无横向溢出，中央独立滚动，主操作可达。
- 验证阶段切换不丢失已填内容，当前步骤具有 `aria-current="step"`，键盘可访问。
- 验证 RAG/模型/条件式风格实例的就绪阻断和缺项定位；重置二次确认；创建与上传的成功、失败反馈。
- 保留既有创建成功、创建失败和路由跳转回归用例。

## 实施与验收记录

- 创建页改为故事核心、参考与边界、篇幅与执行三阶段；步骤切换保留输入，准备度缺项可返回对应字段。
- RAG 未就绪时主操作改为知识库同步入口；创建与上传分阶段反馈，上传失败时可打开已创建任务；重置增加二次确认。
- 工作台布局支持创建页在 900px 显示步骤导航、1440px 显示右侧准备度；1440px 起隐藏底部重复操作，阶段卡片由内容层单独控制内边距。
- 已适配既有创建 E2E 到分阶段表单，并同步首页链接断言为保留作品库来源分类。
- 已通过：`npm run lint`、`npx tsc --noEmit`、`npm test`（205 项）、创建页相关 Chromium E2E（11 项）、`npm run build`。构建仅输出既有 `metadataBase` 配置警告。
