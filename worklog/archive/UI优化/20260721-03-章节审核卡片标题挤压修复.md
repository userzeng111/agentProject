# 章节审核卡片标题挤压修复

## 用户原始诉求

用户在指定章节审核页的侧栏修复验证中仍反馈“章节审核还是存在问题”。

## 当前状态

已完成实现与真实页面验证，并经用户确认收口归档。

## 根因

- 章节卡片标题与章节摘要 `Chip` 在同一行使用 `space-between`。
- 摘要未限制最大宽度且默认不换行，长摘要挤压标题到极窄宽度，造成“第 1 章：雾中发现”逐字竖排。

## 拟定修复

1. 标题区在窄内容宽度下改为纵向排列；宽屏保留左右布局。
2. 标题获得可收缩的剩余空间，摘要限制最大宽度并省略超长文本。
3. 补充长标题、长摘要的章节审核浏览器回归，保证标题不逐字换行且无横向溢出。

## 实施与验证

- 标题在窄内容下改为纵向布局；在宽屏保留同行展示并保有最小可读空间。
- 摘要标签限制最大宽度，视觉上省略超长文本，同时保留完整可访问名称与原生悬停提示。
- 指定任务在 1440×900 真实浏览器中：章节标题宽度约 300px、高度约 32px，摘要宽度约 334px，页面无横向溢出。
- 已通过 `npm run lint`、`npx tsc --noEmit`、对应章节审核浏览器回归（1 项通过）及 `git diff --check`。
