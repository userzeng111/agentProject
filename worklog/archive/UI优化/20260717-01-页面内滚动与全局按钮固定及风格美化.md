# 页面内滚动与全局按钮固定及风格美化

## 用户原始诉求

1. 对现有 UI 结构进行专业化整理和微调：当前很多页面存在较长的下滑区域，导致整个骨架被拉得很长；希望改为在内容区域内部滚动，而不是带着整体结构一起滚动。
2. 页面中存在一些作为全局因素存在的主按键，即便下滑也需要保持顶部显示。
3. 调整 UI 与 UX 的整合效果，并进行整体美观设计。
4. 参考 https://claude.ai/login 的设计风格，在保留现有主体风格的前提下对整体风格进行美观化设计。

## 当前状态

- 已确认调整范围、全局按钮、风格保留要素与依赖策略（见下）。
- 已完成 Explore agent 扫描，掌握当前页面滚动结构与全局元素位置。
- 已基于扫描结果形成具体改造方案，等待用户确认后进入代码修改。

## 澄清结论

- **优先页面**：首页（任务列表）、创建任务页、审核/运行/结果页。聊天页、设置页、归档页等后续批次处理。
- **全局固定元素**：顶部导航栏（AppHeader 已是 sticky，保持并可能增强）、步骤/标签切换栏（需要在内容滚动时保持可见）。
- **风格保留**：现有配色（米纸色背景 `#F7EFE2` + 绿色主色 `#276451`）、玻璃态卡片效果、中文排版与品牌标识。
- **依赖策略**：可引入新依赖（如 Framer Motion 等），但优先使用 MUI 原生能力，仅在能明显提升体验时引入。

## 扫描结果摘要

### 技术栈

- Next.js 14 App Router + MUI v5 + Emotion。
- 主题系统：自定义 `createTheme`，主色 `#276451`、背景 `#F7EFE2`、圆角 10–16px、自定义阴影数组、玻璃态 `.glass-card`。
- 无 Tailwind / shadcn/ui。

### 全局元素

- `AppHeader` 已是 `position="sticky"`，玻璃态背景 + 模糊，无需大改。
- `ClientLayout` 为纵向 flex，`main` 占满剩余高度，默认整体滚动。
- `ProjectShell` 提供面包屑、标题、actions、可选 `StageNav`，但标题栏与 actions **不 sticky**。
- `WorkspaceActionBar` 嵌在可折叠的「请求摘要」卡片里，主操作入口会随折叠消失。

### 页面滚动现状

| 页面 | 当前滚动模式 | 主要问题 |
|------|--------------|----------|
| 首页 `/` | 整体滚动 + 列表内部 `maxHeight:480` 滚动 | 双滚动条、主操作不固定 |
| 创建任务 `/new/` | 整体滚动 | 主 CTA 在底部，易滚出视口 |
| 工作台 `/p/[id]/` | 整体滚动 | 内容极长，Tabs/操作栏不固定 |
| 审核页 `?view=review` | 整体滚动 | 右侧 aside 已 sticky，左侧主内容 Tabs 不固定 |
| 结果页 `?view=result` | 整体滚动 | 阅读器切章会 `window.scrollTo(0,0)`，但整体滚动体验不一致 |
| 聊天页 `/chat/` | 已固定视口 | 无需改造 |

## 改造方案

### 1. 根布局升级（`client-layout.tsx`）

- 将根 `Box` 从 `minHeight: 100vh` 改为 `height: 100vh; overflow: hidden`（桌面端），为子页面提供固定视口基础。
- `main` 设置为 `flex: 1; minHeight: 0; display: flex; flexDirection: column`。
- 移动端仍允许 `min-height: 100dvh`，适配浏览器动态工具栏。

### 2. 新增/升级 `ProjectShell` 固定布局模式

- 增加 `fixedLayout` 能力：占满 `main` 高度，内部分为：
  - 顶部 sticky 区域：面包屑 + 标题/actions + `StageNav`/Tabs。
  - 内容区：`flex: 1; overflow: auto;` 内部滚动。
- 工作台、审核、结果、归档详情统一使用该模式。

### 3. 首页改造

- 去除列表内部 `maxHeight: 480` 的局部滚动。
- 采用「顶部过滤/分类 + 固定高度内容区」：标题与过滤条件 sticky，任务卡片列表在下方内容区滚动。
- 分页器固定在内容区底部（sticky within scroll area）。

### 4. 创建任务页改造

- 将长表单放入固定高度滚动容器。
- 步骤/标签切换栏（如有）或标题区 sticky 在顶部，主 CTA 保持在视口内（可放在底部 sticky 操作栏或顶部 actions）。

### 5. 工作台/审核/结果/归档详情改造

- 使用 `ProjectShell` 固定布局。
- Tabs 栏 sticky 在顶部，切换 Tab 后内容区自动回到顶部。
- 评估将 `WorkspaceActionBar` 从可折叠卡片中拆出，作为页面级固定操作栏或 sticky 头部的一部分。

### 6. 美观化（参考 Claude.ai login）

在保留现有配色与玻璃态基础上，融入以下视觉语言：
- 更柔和的弥散渐变背景（增强现有径向渐变）。
- 更大、更轻的卡片阴影，提升层级感。
- 输入框与按钮 hover/focus 状态更柔和、过渡更平滑。
- 页面/卡片入场使用轻量 fade/slide 动画（优先 MUI `Fade`/`Grow`；必要时引入 `framer-motion`）。
- 更宽松的留白与更聚焦的内容居中布局。

### 7. 依赖

- 优先使用 MUI 原生动画与布局能力。
- 如需要更连贯的页面过渡或卡片动画，可引入 `framer-motion`。

## 风险

- 根布局改为固定视口后，若子页面未同步改造可能出现内容截断。
- `sticky` 定位在多层 `overflow` 容器中可能失效，需要保证滚动容器层级正确。
- 移动端 `100vh` 与 `100dvh` 差异可能影响滚动体验，需逐页验证。
- `WorkspaceActionBar` 拆出可能改变现有交互流程。

## 原型决策

- **选定原型页面**：首页（任务列表 `/`）。
- 原因：问题最典型（整体滚动 + 内部 `maxHeight` 双滚动条），且改造后效果最明显；结构相对独立，便于验证固定布局模式。

## 首页改造方案（原型）

### 目标

- 消除整体页面滚动与列表内部滚动的双滚动条问题。
- 标题栏、「创建任务/归档」主按钮、作品库 Tabs、分页器保持可见。
- 仅任务卡片列表在固定区域内滚动。
- 保留现有配色与玻璃态，融入 Claude.ai 风格的柔和渐变、轻阴影与圆润卡片。

### 结构改造

1. **根布局配合**：
   - `client-layout.tsx` 的 `main` 改为 `flex: 1; minHeight: 0; display: flex; flexDirection: column`。
   - 首页根 `Box` 占满 `main` 高度（`height: 100%`），自身为纵向 flex。

2. **首页内部布局**：
   ```
   ┌─ 标题栏（flexShrink: 0）─────────────┐
   │  小说工坊 + 描述 + 创建任务/归档按钮  │
   ├─ 内容区（flex: 1, overflow: hidden）─┤
   │  ┌──────────────┐ ┌──────────────┐  │
   │  │ 作品库（md=8）│ │ 侧边栏（md=4）│  │
   │  │ height:100%  │ │ height:100%  │  │
   │  │ 内部列表滚动  │ │ overflow:auto│  │
   │  └──────────────┘ └──────────────┘  │
   └─────────────────────────────────────┘
   ```

3. **`TaskTabPanel` 改造**：
   - 外层占满高度（`height: 100%; display: flex; flexDirection: column`）。
   - 标题区、Tabs：`flexShrink: 0`。
   - 列表区：`flex: 1; overflow: auto;`（去掉 `maxHeight: 480`）。
   - 分页器：`flexShrink: 0;` 粘在面板底部。

4. **侧边栏**：
   - `height: 100%; overflow: auto;`，内容超过时独立滚动，不影响主列表。

### 美观化改造

1. **背景**：增强现有径向渐变，加入更柔和的弥散光晕（保留 `#F7EFE2` 基调）。
2. **卡片**：
   - 作品库卡片使用更大圆角（20px）与更轻阴影。
   - 任务卡片 hover 效果更柔和（边框色变化 + 轻微上浮）。
3. **按钮**：
   - 主按钮「创建任务」使用渐变或更饱满的阴影，hover 时轻微上移。
   - 文字按钮与 outlined 按钮 focus ring 更柔和。
4. **动画**：
   - 页面整体使用 MUI `Fade` 入场。
   - 任务卡片列表可加轻量 stagger fade-in（优先用 MUI `Grow`；如效果不够再引入 `framer-motion`）。
