# 审核决策抽屉滚动修复

## 用户原始诉求

“这个提交审核部分内栏被固定了，我无法进行滑动，你要调整这部分”。

## 当前状态

已实施：审核决策抽屉纸面容器显式占满动态视口高度，并使用纵向弹性布局和隐藏的外层溢出；中间内容区成为唯一可滚动区域，且其中的配置与意见卡不再被弹性压缩，顶部标题和底部通过/拒绝操作保持固定。

## 修复方案

将抽屉纸面容器固定为视口高度的纵向弹性布局，内容区作为唯一的 `minHeight: 0`、`overflowY: auto` 滚动区域；顶部标题与底部通过/拒绝操作保持固定。补充浏览器断言，验证内容超高时滚动位置可变化、固定操作仍可见，且移动端不发生横向溢出。

## 验证

- `npm run lint` 与 `npx tsc --noEmit` 通过。
- 审核抽屉的桌面、移动端 Playwright 回归通过：超长内容可滚动，底部决策操作固定，移动端无横向溢出。
