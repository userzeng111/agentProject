# 首页布局优化与分页设计

## 用户原始诉求
1. 首页排版导致需要下滑才能看到后续内容，需要更好的UI管理
2. 非表单列表的内容，尽量避免需要下滑改为page分页
3. 除开文章内容外
4. 参考知乎网页端的设计

## 实施方案

### 首页布局重构
- 双栏布局（主区 8:4 侧边栏），参考知乎网页端
- 主内容区：紧凑标题栏 + Tab 分组任务列表（待处理/运行中/失败）+ 前端分页
- 侧边栏：统计卡片竖排 + 功能特性竖排
- 任务卡片紧凑化：标题+状态+查看一行，摘要截断，元信息caption
- 首页独立使用 Container maxWidth="lg" (1200px)

### 归档页分页
- 后端分页：`GET /api/archive?page=1&page_size=10`
- 前端 Pagination 组件，标题旁显示"共 N 条"

### 布局架构调整
- layout.tsx 移除 Container，改用 Box 提供基础 flexbox 布局
- 各页面各自管理 Container maxWidth（首页 lg，其他页面 md）
