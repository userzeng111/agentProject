# UI/UX 界面优化重构

## 用户原始诉求
采用 agent team 模式，调整 UI 和 UX。采用 skills，参考现有颜色主题风格，参考 MUI，设计优化界面的方法。简洁现代，明确区分按钮设计，设计按钮阴影等，玻璃态等内容，布局也需要调整，各个功能模块的页面跳转需要合理符合人类使用规则。

## 当前状态

### 问题审计结果

**高优先级：**
1. 无全局导航 — 没有顶部导航栏，用户无法快速切换页面
2. 按钮无类型区分 — 主/次/危险操作视觉完全相同
3. 无步骤指示器 — 任务生命周期没有可视化进度
4. 加载/空状态缺失

**中优先级：**
5. 阴影单一 — Card只用一种阴影，无层次感
6. 信息密度过高 — 工作台434行平铺，信息过载
7. 缺少辅助色 — 无 success/warning/error/info
8. 卡片无层次区分

**低优先级：**
9. 无玻璃态效果
10. 无过渡动画
11. 圆角过于统一

### 视觉规范设计结果

- **色彩扩展**：新增 success(#2e7d5b)/warning(#c47a2a)/error(#b44a3f)/info(#4a7a8a) 辅助色
- **按钮系统**：4种类型(Primary/Secondary/Danger/Ghost)，各有不同阴影和状态
- **玻璃态规范**：backdrop-filter: blur(12px), 背景rgba(255,250,242,0.65)
- **阴影层级**：sm/md/lg/x1 四层
- **圆角规范**：卡片16px、按钮12px、输入框12px、小元素8px
- **间距规范**：页面边距24-32px、卡片内边距24px、组件间距8-16px

### UX优化方案

1. 全局顶部导航栏（玻璃态AppBar）
2. 步骤指示器（Stepper）— 创建→运行→审核→结果→归档
3. 页面跳转优化（面包屑、快速入口）
4. 工作台Tab分区（实时日志/章节进度/详情）
5. 状态反馈增强（Skeleton/Snackbar）

### MUI技术方案

核心 theme 扩展：色彩/阴影/圆角/按钮/玻璃态AppBar

## 讨论结论

- 用户确认整体方案方向
- 按 P0→P3 优先级顺序实施
- 保持暖色古典文学基调不变
- 采用MUI原生方案不过度引入新库
