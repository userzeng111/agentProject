# UI/UX 体验重塑阶段 1

**用户原始诉求**：针对现在的 UI 进行优化设计，给出整体 UI 设计和重构思路，调用项目已有技能进行综合设计与头脑风暴，选择体验重塑型方向（B 方向）并推进实施。

**当前状态**：已归档。UI/UX 体验重塑阶段 1 已完成，范围为设计系统、深色模式基础、通用组件层、Root Layout 接入与 E2E 抽象层。完整体验重塑的阶段 2-4 已拆入新的 active 任务继续跟进。

**设计方案摘要**：

- 产品定位从「任务管理器」转向「AI 小说创作工坊」，核心单位从 task 改为 project。
- 路由重构：`/p/[projectId]` 作为作品相关页面前缀，首页改为作品库，工作台改为固定状态条 + 仪表盘 + 锚点区块。
- 设计系统：保留暖色书卷基调，系统化色彩/字体/间距/阴影/动画，新增深色模式。
- 通用组件层：新增 `ProjectShell`、`StageNav`、`DecisionBar`、`NotificationCenter`、`ConfirmDialog` 等 20+ 组件。
- 关键页面：首页作品卡片网格、新建向导、工作台仪表盘、审核页左右分屏、结果页阅读器。
- 实施阶段：分 4 阶段推进（设计系统 → 首页/工作台 → 审核/结果/章节 → 暗黑模式与精调）。

**阶段 1 计划**：

- 建立统一 Design Token 与深色模式基础。
- 新增 10 个通用组件：`PageContainer`、`StageBadge`、`ProgressBar`、`EmptyState`、`LoadingOverlay`、`SkeletonGrid`、`ConfirmDialog`、`NotificationCenter`、`DecisionBar`、`ModelSelect`。
- 更新 `layout.tsx` 接入 `AppThemeProvider`、`NotificationProvider`、动态背景与 metadata 导出。
- 创建 E2E 测试抽象层（`routes.ts`、`selectors.ts`、`helpers.ts`）。

**Why**：当前 `task-run-client.tsx`（1783 行）、`task-review-client.tsx`（1744 行）过大，样式三轨并行，通用组件缺失，页面纵向堆叠导致用户需要大量滚动。体验重塑能从根源上改善信息架构和可维护性。

**How to apply**：

1. 使用 `subagent-driven-development` 技能按 Task 执行阶段 1 实施计划。
2. 每个 Task 完成后运行对应测试与构建校验。
3. 阶段 1 全部完成后归档本问题文档并提交。
