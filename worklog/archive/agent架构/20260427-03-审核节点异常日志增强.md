# 审核节点异常日志增强

## 用户原始诉求

增强3个审核节点（outline、chapter、verification）的异常日志记录，确保 auto_review 异常时能正确降级到人工审核。

## 当前状态

- 3个文件都有相同的 auto_review 异常处理模式：try/except 捕获异常，构造 `ReviewDecision(approved=False, auto_escalated=True, ...)`，设置 `force_manual=True`，然后进入人工审核中断
- `outline.py` 和 `chapter.py` 的 except 块**没有 logger 日志记录**
- `verification.py` 已有 logger（`from app.observability import get_logger`），且已有异常日志

## 修改方案

### outline.py
1. 文件顶部增加：
   ```python
   from app.observability import get_logger
   logger = get_logger(__name__)
   ```
2. 在 `if state.get("auto_review") and auto_review_executor_available:` 行后增加 INFO 日志：
   ```python
   logger.info("大纲审核节点: auto_review=%s, executor_available=%s", state.get("auto_review"), auto_review_executor_available)
   ```
3. except 块开头增加：
   ```python
   logger.error("大纲审核节点: auto_review 异常: %s", e, exc_info=True)
   ```

### chapter.py
1. 文件顶部增加：
   ```python
   from app.observability import get_logger
   logger = get_logger(__name__)
   ```
2. 在 `if state.get("auto_review") and auto_review_executor_available:` 行后增加 INFO 日志：
   ```python
   logger.info("章节审核节点: auto_review=%s, executor_available=%s", state.get("auto_review"), auto_review_executor_available)
   ```
3. except 块开头增加：
   ```python
   logger.error("章节审核节点: auto_review 异常: %s", e, exc_info=True)
   ```

### verification.py
- 已有 logger 和异常日志，格式一致，不需要修改

## 影响与风险

- 仅增加日志记录，不改变业务逻辑
- 异常降级到人工审核的行为保持不变
- 无风险
