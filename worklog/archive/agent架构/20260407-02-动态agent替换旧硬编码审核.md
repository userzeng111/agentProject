# Phase 2：动态 Agent 系统替换旧硬编码审核

## 问题标题
Phase 2：动态 Agent 系统集成替换旧硬编码审核架构

## 用户原始诉求
继续推进 Phase 2，将现有 auto_reviewer.py 硬编码审核替换为动态 Agent 编排系统。

## 当前状态
已完成验证，待收口。动态桥接已确认接入主图自动审核链路，并补上“旧审核器不可用时仍可由动态桥接兜底”的图层验证与修复。

## 本轮实现目标
1. 补图层测试，证明 `DYNAMIC_AGENT_REVIEW=true` 时主链路实际走 `DynamicReviewBridge`
2. 修复主图分支判断，使动态桥接不再依赖旧 `AutoReviewManager` 必须可用
3. 跑自动审核相关回归，确认 outline / chapter / verification 三段审核都兼容

## 关键集成点分析

### 调用链
```
main_graph.py (build_graph 闭包)
  └─ AutoReviewManager 实例化 (line 91)
  └─ review_outline() → auto_review_manager.review(payload, policy) (line 236)
  └─ review_chapter_pair() → auto_review_manager.review(payload, policy) (line 377)
  └─ review_verification() → auto_review_manager.review(payload, policy) (line 494)
```

### 替换策略
采用"桥接层"模式：
1. 创建 DynamicReviewBridge — 将 TaskOrchestrator 包装为 ReviewDecision 兼容接口
2. 在 main_graph.py 的 build_graph 中增加开关
3. 保持 ReviewDecision 输出格式不变，确保下游不受影响
