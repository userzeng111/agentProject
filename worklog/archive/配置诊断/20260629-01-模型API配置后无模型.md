# 模型 API 配置后无模型

## 问题标题

模型 API 配置后无模型

## 用户原始诉求

用户反馈设置 `LLM_API_KEY` 与 `LLM_BASE_URL` 后仍然没有模型。

## 当前状态

已定位，暂不修改代码。

## 排查结论

- `apps/agent-runtime/.env` 中已存在 `LLM_API_KEY` 与 `LLM_BASE_URL=https://api.udcode.cn`，配置文件位置正确。
- 直接用同一份配置调用网关 `https://api.udcode.cn/v1/models` 成功，返回 5 个网关模型。
- 当前正式后端 `localhost:8000/api/models?refresh=true` 只返回 14 个 `registry` 本地画像模型，没有 `gateway` 来源模型，因此前端会显示没有可选网关模型。
- 用同一代码新启动临时后端 `localhost:8012` 后，`/api/models?refresh=true` 返回 17 个模型，其中包含 `gateway`/`gateway+registry` 来源模型。

## 当前判断

根因是 `localhost:8000` 上运行的后端进程仍处于旧加载状态，没有重新读取最新 `.env`；不是变量名错误，也不是 `LLM_BASE_URL` 缺少 `/v1`。

## 后续建议

重启正式后端 `localhost:8000`，然后重新请求 `/api/models?refresh=true` 或刷新前端页面验证模型列表。

## 2026-06-29 热启动验证

- 已停止旧的 `localhost:8000` 后端进程，并重新启动后端。
- 已清理旧前端进程，并显式启动 `localhost:3000` 前端，避免端口漂移到 3001。
- `localhost:8000/api/health` 返回正常。
- `localhost:8000/api/models?refresh=true` 返回 17 个模型，其中包含 5 个 `gateway`/`gateway+registry` 来源模型。
- `localhost:3000` 返回 200，前端可访问。
