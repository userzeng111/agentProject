# 向量增量构建与生成聊天 UI 优化

## 问题标题

向量库从全量重建改为增量构建，并优化结果页与聊天页展示

## 用户原始诉求

用户要求多 Agent 并行完成以下事项：

1. 向量库从全量重建改为增量构建，降低重建耗时。
2. 移除结果页章节分页阅读器下方重复的全量全文显示。
3. 缩小 AI 对话结束后 token 总量的 UI 占位，避免强制拉伸对齐。
4. 调整思考过程 UI，并按 `ui-ux-pro-max` 指引完成聊天页体验优化。

## 当前状态

实现与验证已完成：增量索引采用来源清单与内容指纹，首次或旧索引不兼容时明确要求用户显式全量重建，后续仅嵌入新增或变更来源，并同步清理已删除来源；结果页已去除重复全文；聊天 token 与思考过程 UI 已完成响应式和可访问性优化。仓库不存在 `src/Cargo.toml`，本任务不执行 Cargo workspace patch 版本递增。

## 初步约束

- 不覆盖当前工作区已有的未提交改动。
- 增量构建必须保持向量索引、元数据和删除/更新语义一致，并有回归测试。
- 聊天 UI 继续使用现有 MUI 主题 token，保持键盘访问、深浅色与窄屏可用。
- 结果页保留逐章分页、复制、导出等现有行为，仅移除重复的全量全文区域。
- 完成后需执行后端目标测试与 ruff、前端 lint/test/build、相关 Playwright、接口与页面 smoke 检查；未完成这些验证前不得归档或提交。
