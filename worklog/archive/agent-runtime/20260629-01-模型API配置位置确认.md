# 模型 API 配置位置确认

## 问题标题

模型 API 配置位置确认

## 用户原始诉求

用户询问：现在要改项目的模型 API，告诉我在哪里。

## 当前状态

已归档。已只读定位模型 API 相关配置与调用入口，已向用户说明位置；未修改模型 API 实现代码。

## 定位结论

- 后端实际运行配置入口：`apps/agent-runtime/.env`，示例为 `apps/agent-runtime/.env.example`。
- 配置字段定义：`apps/agent-runtime/app/settings/config.py`。
- 模型网关 HTTP 调用实现：`apps/agent-runtime/app/llm/gateway_client.py`。
- 模型列表、默认模型与模型能力目录：`apps/agent-runtime/app/llm/model_catalog.py` 与 `apps/agent-runtime/data/model_capabilities.json`。
- 前端 API 基址只指向本地后端：`apps/web/src/lib/api.ts`。

## 后续改造边界

- 若只是更换 OpenAI-compatible 模型网关、API Key、默认模型，通常只改 `.env` 中 `LLM_BASE_URL`、`LLM_API_KEY`、`DEFAULT_CHAT_MODEL`。
- 若新增模型为小说任务可选模型，需要补模型目录画像和能力配置。
- 若新增非兼容协议或多供应商多 Key，需要单独设计 provider registry 或 per-model credential 方案，并补后端协议、前端设置与自动化测试。
