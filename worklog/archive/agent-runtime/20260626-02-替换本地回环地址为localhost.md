### 审计修复记录
- 代码审计发现：浏览器访问 `localhost` 时，ASGI 层拿到的 `request.client.host` 可能是解析后的本地回环 IP，原先只判断字符串 `localhost` 会导致本地开发/E2E 请求重新进入限流。
- 已按 TDD 增加 `test_loopback_ip_is_exempt_when_accessing_localhost`，先复现第 3 次请求被 429 的失败，再改为通过 `ipaddress.ip_address(...).is_loopback` 识别回环地址。
- 追加覆盖 `unknown` / 空客户端 host 的本地调试豁免边界，保持既有行为。
- 已同步 `.agents` 下接口冒烟和全量 API 自检 skill 的默认地址为 `localhost`。
- 验证：`uv run --project apps/agent-runtime pytest apps/agent-runtime/tests/test_rate_limit_middleware.py::test_loopback_ip_is_exempt_when_accessing_localhost -q` 通过。

## 影响与风险
- 开发环境统一使用 `localhost` 后，访问 `http://127.0.0.1:xxxx` 的场景可能遇到跨域或连接问题，需统一使用 `http://localhost:xxxx`。
- 启动脚本中的 `--host localhost` 在多数系统上仍可正常解析到 IPv4 回环，已验证测试无异常。
- 测试代码中服务器绑定地址改为 `localhost` 后，当前系统解析为本地回环地址；限流层已使用标准库回环判断兜底 IPv4/IPv6 差异。
